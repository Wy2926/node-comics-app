# 手机界面与视觉令牌

逐页替换手机视图，已落地书架、平台导航、浏览与来源管理、扩展详情、历史与更新、漫画详情与目录、阅读工具栏与弹层、多标签浏览器、更多与设置入口、翻译与账号设置、外观及通用设置、安全设置与锁定页、导航定制和全局模式提示。沿用现有来源、书库查询、筛选排序、导入、阅读、下载和批量管理逻辑。桌面与电视入口继续使用现有布局。后续页面按此文逐项收敛，不另建业务状态或迁移漫画数据。

## 视觉方向

参考 NodeLane 插件端书架的信息层级：大封面、来源与阅读状态、直接导入、搜索和批量操作。手机使用平静的纸面和轻边框，避免将桌面的粗描边、硬阴影和大横幅照搬到小屏。仅参考布局和语义，独立实现 Flutter/UIKit 视图，不复制同级 GPL 仓库源码或漫画封面。

| 令牌 | 手机约定 |
| --- | --- |
| 画布／表面 | 浅色近白纸面、深色炭灰；书籍封面保持原色 |
| 文字 | 系统字体，大标题 32、书名 15、正文 16、辅助信息 12；遵循系统文字缩放 |
| 强调色 | 默认 NodeLane 蓝；继承已有用户主题的强调色，不改变状态色含义 |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24；手机页面边距 20 |
| 圆角 | 控件 12、封面 14、容器 20；清晰层级，少量阴影 |
| 点击区 | 至少 44 pt；正文不压在封面上；长按继续批量选择 |
| 动效 | 短暂状态过渡；尊重减少动态效果，不新增常驻动画或整页模糊 |

## 导航与书架

- 手机底栏把漫画、动画、小说归入一个“书架”入口；书架标题下选择媒体类型。保留现有媒体隐藏偏好、导航顺序、路由和角标。其余默认入口为更新、历史、浏览、更多；超过五项时通过更多入口展开，不挤压按钮。
- iOS 使用嵌入式 UIKit `UITabBarController`，由运行中的系统绘制外观、材质与辅助功能。当前系统采用 Liquid Glass，较旧系统使用其原生外观。不用 Flutter 模糊胶囊冒充原生底栏。
- Android 使用统一令牌的底栏：实色表面、轻边框、明确的选中状态，保留系统返回与安全区。
- 书架常用操作直接可见：标题、媒体切换、导入、搜索、筛选。更新、随机阅读等次要操作保留在菜单；选择模式继续使用既有批量操作。
- 网格默认自适应两列，已有列数在可用宽度范围内生效，保留网格／仅封面／列表模式；书名放在封面下方，来源与状态尽量单行。继续阅读调用既有入口，不为视图增加逐本历史订阅。
- 空书架提供导入与浏览入口；筛选无结果明确提示调整筛选，不把用户已有书籍误报为空书库。

原生参考：[Apple Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)、[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[UITabBarController](https://developer.apple.com/documentation/uikit/uitabbarcontroller)。

## 浏览与来源

- 将原来的六个横向标签改为“媒体选择 + 来源／扩展”两层；切换媒体时保留当前分区。已有跳转请求在浏览页保持挂载时也生效，隐藏媒体的设置即时同步，并按媒体身份保留选中项。
- 来源页保留全局搜索、来源筛选、最近使用、置顶、语言分组和本地来源。来源卡片把标题与元信息放在上方，最新内容／置顶放在单独操作行，避免挤压长名称。
- 扩展页保留名称搜索、语言筛选、版本与仓库信息、安装／更新／设置及卸载确认。常用动作显示文字；仓库配置有直接入口，空结果可重置查询或前往配置，不增加推荐源或自动安装。
- 查询、来源身份、安装更新和仓库持久化仍由现有 provider／repository 负责。新卡片与页头只接收显示内容和回调；继续使用原 TabBarView 与按需列表，滚动位置按媒体和分区保存。
- 软件键盘显示时收起标题与分区，保留搜索和筛选；收起键盘后自动恢复。页头订阅实际视图尺寸变化，并保留外层安全区与文字缩放；短屏／横屏限制页头高度并允许滚动。媒体菜单与主要操作保持至少 44 pt 点击区。
- 来源筛选、语言列表和扩展库管理统一为轻背景、分组卡片和明确空态。筛选按原语言分组；开关、勾选仍写入原字段。无来源时可以直接进入对应媒体的扩展分区，无语言时可进入扩展库配置。
- 扩展库卡片分开显示名称、主机名、可见性开关和复制／浏览／移除操作；空库只展示一个添加入口，有库时将添加操作固定于底部安全区。添加弹窗支持长提示、大字体和键盘下滚动，移除确认显示目标名称；校验、下载解析、去重与持久化沿用现有流程。
- 弹窗控制器在退场动画结束后释放；刷新完成时仅更新仍挂载的页面。
- 扩展详情按“名称／版本／语言 → 来源设置 → 高级操作”排列，缩小原来占据首屏的大图标；图标加载沿用扩展列表的入口。设置写入、编辑代码、Cookie 清理和卸载仍调用原流程，卸载保留确认；开发工具仍只在开发者模式下显示。设置弹窗允许文字换行与键盘下滚动，按钮交给弹窗自行换行。

## 历史与更新

- 使用大标题、媒体菜单和常显搜索，保持独立的历史与更新入口。更新保留各媒体的数量角标、刷新／停止和错误入口；删除全部仍需原确认。媒体隐藏偏好即时同步，按媒体身份保留选中项，只有实际切换媒体才清空查询；没有可见媒体时隐藏维护操作。
- 记录仍按原日期规则分组。手机行改为可伸展卡片：封面进入详情，文字区域调用既有继续阅读入口，删除或下载保留独立点击区；已读标记、下载状态与章节查询不在卡片中计算。
- 查询无匹配时显示“无结果”与重置入口，无记录时显示原业务空态。键盘显示时收起标题和媒体栏，收起后恢复；列表末尾为平台底栏留白，按媒体保存滚动位置。
- 历史继续阅读沿用现有“跳到下一未读章”的规则。已读完且没有下一未读章时，既有入口不会跳转；本轮未更改阅读规则。

## 漫画详情与目录

- 手机详情按“封面与书名 → 阅读／继续阅读与收藏 → 简介和分类 → 次要操作 → 目录”排列。原阅读按钮的未读判断、历史恢复入口、收藏去重与分类选择保持不变；全部已读时仍沿用原规则隐藏主阅读按钮，章节行可直接打开。
- 封面缩小为 96 × 144，手机首屏不再绘制大幅背景封面；点封面仍打开原图查看器，点标题搜索、长按标题复制的入口保留。大字体时封面与文字上下排列，按钮允许换行。
- 网页、追踪、更新日历、本地信息编辑、推荐与相关作品收在可展开区域；刷新、分享、迁移等保留原菜单。未新增来源解析、查询字段或阅读规则。
- 目录标题旁提供筛选与本地追加章节。手机章节行显示已读／未读、书签和既有进度信息，标题与元信息可换行，不使用跑马灯；缩略图、章节阅读、滑动操作与下载仍走原入口。选择时隐藏行内下载按钮，批量操作保持原逻辑。
- 长按后的 Android 系统返回先取消选择；底部操作避开系统安全区。没有后续章节时不展示“标记后续已读”操作，避免原入口越界；删除确认允许滚动和按钮换行。本地信息编辑弹窗在键盘上方可滚动，取消不写入，控制器在退场后释放。
- 详情筛选使用独立的手机弹层容器，直接接入原筛选、排序和显示选项。标签按文字缩放确定高度，长标签可横向滚动；当前分区按内容高度展开，上限为屏幕可用高度的 70%，内容独立滚动，分区通过标签选择。桌面与电视继续使用原弹层。

## 阅读工具栏与弹层

- 上方只显示返回、书名／章节、书签；在线来源的刷新和网页入口收进菜单。下方以页码和滑杆为主，上一章／下一章放两侧；第二行固定为目录、翻译、显示、设置，文字与图标同时可见。
- 工具栏叠放在阅读画面上，不因自身展开收起挤压页面；隐藏时不接收点击和辅助功能焦点。短屏与大字号时限制高度并允许控件区滚动，控件滚动不触发阅读页的滚动隐藏逻辑。隐藏工具栏后的页码和自动滚动按钮避开底部安全区。
- 进度滑杆复用原页码监听与跳页回调，随既有阅读方向反转；零页／单页禁用拖动。显示菜单复用阅读模式、裁剪和双页回调，横向连续模式仍禁止双页切换。页面索引换算、预加载和阅读进度存储不在新控件中实现。
- 目录使用有界底部弹层，当前章节高亮，章节名可换行，书签为独立操作；章节排序、筛选与切章沿用原流程。列表为空或当前章节被筛除时不越界定位。此弹层只接入漫画阅读器，动画播放器的原目录入口保持原样。
- 设置保留原阅读模式、通用和自定义筛选三页及全部 provider。手机标签可横向滚动，字号放大时仍可关闭；选项名称与当前值分行，颜色增强滑杆单独占一行，闪屏颜色选项允许换行。自动滚动的暂停／恢复规则保持原样。
- 阅读器与网页共享翻译面板和原控制器。手机明确分开“翻译当前阅读范围”与“原图／译图显示”；显示切换不自行启用翻译。未登录保留设置入口，未开始且没有信息的状态行隐藏，已有逐页恢复操作继续显示。不增加来源／服务分支，不改任务身份、渠道、费用或恢复协议。

## 多标签浏览器

- 浏览页提供独立的“打开网页”入口，无需先安装来源。网址弹窗与浏览器内共用输入视图，沿用 HTTP／HTTPS、长度和嵌入凭据校验，非法输入留在弹窗内提示；取消不导航，控制器随弹窗释放。
- 上方显示返回应用、页面标题／主机名与菜单，点击地址区域编辑完整网址。下方固定后退、前进、翻译、标签四项，禁用状态取自原历史记录；刷新、新标签与网站登录状态清理仍调用原流程。
- 标签收进按需打开的列表弹层，显示标题、主机名和当前选中状态；选择与关闭为独立点击区。新标签操作固定在安全区内，达到原有 12 页上限时禁用并解释原因。短屏、大字号时限制工具栏高度，标签列表与输入弹窗可滚动。
- 原 WebView 保活、历史、锚点、翻译控制器和释放规则继续负责行为。视图只显示加载进度和主框架连接失败状态，失败保留手动重试；不把子资源失败当整页失败，不记录原始错误或签名网址。
- iOS 的新窗口链接在导航回调中转交原标签创建入口并取消原页跳转。当前 WebView 依赖对未接管的新窗口会回退到原页加载；在创建原生新窗口前处理可避免重复导航，也无需额外保活控制器。Android 保留原新窗口入口。

## 更多与设置入口

- 更多页以设置和漫画翻译为首组，阅读开关、书库工具和关于分别分组，移除占据首屏的大标志。下载队列、分类、数据与存储、统计、日历继续使用原路由；历史入口仍按原隐藏偏好显示。
- 仅已下载与隐身模式使用整行可操作的自适应开关，标题、说明与开关合并为一个辅助功能目标。写入与 Discord 状态处理保留在原组件，展示控件只接收值和回调。
- 设置入口按阅读、应用设置、数据与存储分组，搜索仅匹配当前可见的标题和说明。媒体隐藏偏好即时同步；无结果可重置，进入子页后返回保留查询。搜索不读取账号、来源或服务数据。
- 菜单行随文字换行增高，整页可滚动；更多页末尾为原生／令牌底栏留白。漫画翻译快捷入口全屏打开对应设置，返回恢复更多页；其余设置子页继续逐项整理。

## 翻译与账号设置

- 页面按账号、翻译和本机缓存分组。登录按钮和系统浏览器说明直接可见；已登录展示账号名称与退出入口，大字号时图标和账号名称上下排列。只展示已接入的账号能力，不增加额度、付费或渠道配置入口。
- 目标语言通过有界底部弹层选择，四种语言与原菜单相同。当前项明确标记，选项可滚动，关闭或保持当前项不写入；选择新语言仍由原服务保存并替换运行时。
- 初始化期间与服务操作期间禁用操作，页头显示进度；异步失败使用原服务的安全错误文案，缓存清理完成后显示结果反馈。状态区和分组身份保持稳定，避免在列表底部操作时因插入状态项打乱位置。
- 登录、退出、语言持久化、缓存删除与回执恢复继续由 `TranslationService` 负责。页面只保存进度文案和初始化结果，离开后不再更新显示。初始化失败不展示底层异常，也不提供重复等待同一失败任务的假重试。

## 外观设置与模式提示

- 外观页按主题、界面和日期显示分组。跟随系统／浅色／深色合并为一个主题入口；纯黑只在深色下显示，启用时隐藏混色滑杆，保留原混色值。主题和配色写入仍调用已有 provider。
- 配色、语言和字体使用可搜索的全屏选择列表，保留全部原选项。字体列表只展示名称，不为预览加载字体；明确选择默认字体与取消页面分别处理。当前项有勾选，取消或选择当前值不写入。
- 界面缩放保留原 85%–125% 范围，拖动即时预览，仅在结束时持久化。相对时间戳和日期格式保留原规则，日期示例与格式分行展示。导航定制沿用原路由，手机布局见下节。
- 选择列表按需构建，搜索区随内容滚动，为键盘、短屏和大字号保留可访问空间。选择页面只回传选项；外观页面负责连接原设置回调，不新增设置状态或存储逻辑。
- 手机的仅已下载／隐身提示共用一个顶部安全区，使用令牌表面、文字与图标颜色，大字号允许换行。外层统一扣除已占用的顶部安全区，子页无需读取模式状态；底部安全区、页面实例及滚动状态保留，阅读页面继续隐藏提示。

## 通用设置与导航定制

- 通用页按书架、应用设置和高级分组。自动更新行始终显示当前频率（含“从不”），使用已有全屏选择列表；取消或选择当前项不写入。关闭自动更新时隐藏仅 Wi-Fi 开关，保留原偏好，重新开启后恢复显示。导航定制、双击搜索提示与欢迎界面继续调用原入口。
- 网络、推荐权重和 Discord 默认收起，展开仅显示控件。DoH 使用独立开关，展开网络分组不会启用服务；服务选项、自定义地址、DNS、用户代理和 Cloudflare 代理仍写入原 provider／store，保留原校验规则。地址行最多显示两行，完整内容在编辑弹窗中查看。
- 文本弹窗可滚动，键盘上方保留取消与确认；取消和明确保存空值分别处理。控制器随弹窗释放，不在发起方提前销毁。推荐权重沿用四个原字段，拖动结束时保存，重置仍使用原默认值；Discord 与内存显示保留原回调及平台能力边界。
- 导航行使用本地化标题、独立拖动区和自适应开关，保留原顺序字段、媒体身份与隐藏偏好。浏览和更多始终显示；漫画、动画和小说仍合并为书架入口，多余底栏入口仍由更多页承接。原电视布局开关保留在高级分组。
- 手机排序写入新列表，按当前 Flutter 拖动回调提供的目标索引移动，不修改旧偏好列表。启动顺序仅在创建路由器时读取，排序不再重建路由器或丢弃当前设置页；已有主页面监听偏好并更新平台底栏，重启使用保存后的首个可见入口。

## 安全设置与锁定页

- 手机安全页使用分组开关和独立说明，明确区分检查设备能力、可用、不可用和验证中的状态。检查或验证期间禁用操作，失败或取消保留原值并显示简短反馈，不展示底层异常；开启与关闭均须原系统认证成功。
- 锁定页以锁图标、状态和一个解锁按钮为主，短屏与大字号时可滚动，按钮避开系统安全区。页面保持不透明，阻止点击穿透，并从 Flutter 辅助功能树中屏蔽下层内容；无关闭或跳过入口。
