# 移动端界面与视觉令牌

iOS、Android 手机与 Android 平板共用视觉令牌和基础组件，桌面／电视保留各自布局。页面负责呈现、草稿和回调，查询、持久化、来源解析、播放与翻译由现有服务承担。

专题契约：[阅读设置](design/reader-settings-redesign/design.md)、[来源插件](SOURCE_PLUGINS.md)、[翻译架构](TRANSLATION_ARCHITECTURE.md)、[国际化](INTERNATIONALIZATION.md)、[发行与更新](APP_UPDATES.md)。本文维护界面行为、设计参考和设备验证边界。

## 视觉令牌

数值与主题实现以 [`NodeLaneTokens`](../lib/theme/nodelane_tokens.dart) 为准，业务页面复用文字角色和组件，不单独覆盖字号、圆角、输入装饰或颜色。

| 项目 | 约定 |
| --- | --- |
| 字体 | 继承用户字体及系统缩放；页面标题 34、详情标题 26、作品强调标题 22、面板标题 20、设置名 17、正文／输入 16、书名／值／按钮 15、说明 14、次要信息 13、徽章 12 |
| 间距 | 4／8／12／16／20／24；页面边距 20、分组内边距 16 |
| 圆角 | 封面 10、分组 18、输入／分段／模态 24；文字按钮胶囊形、工具按钮圆形 |
| 几何 | 点击区至少 44，输入／主次按钮高至少 48，设置行至少 56，目录行至少 72；图标 24、紧凑图标 20、网站图标 40 |
| 强调色 | 默认 `#006EFF`，继承用户主题；普通图标用正文色，操作／选中／进度用强调色，错误与破坏性操作用错误色 |
| 无障碍 | 大字号按内容增高或换行；高对比度玻璃改实色；动效遵守减少动态效果；隐藏控件不接收点击、键盘或语义焦点 |

| 色彩角色 | 浅色 | 深色 |
| --- | --- | --- |
| 画布／表面／次级填色 | `#F5F6FA`／`#FFFFFF`／`#EBEEF4` | `#13171D`／`#1E242C`／`#292F39` |
| 正文／辅助文字 | `#171A21`／`#697180` | `#F0F3F8`／`#A9B4C4` |
| 分割线 | `#E7EAF0` | `#353E4A` |
| 输入底色／细边 | `#FFFFFF`／`#DDE2E9` | `#303844`／`#46505F` |

纯黑模式使用黑色画布和 `#0A0A0A` 表面。轻选中态使用 11% 强调色；开关关态由辅助色以 28% 混入表面。

内容分组为实色，无模糊和投影。输入使用 92% 填色、0.75 细边、局部模糊 8 和轻阴影；浮动工具模糊为 16。抽屉／对话框使用 97%→95% 高遮盖度表面和单层细边，遮罩为黑色 54%。高对比度移除玻璃阴影。Flutter 玻璃是有界模糊，系统材质参考 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。

Flutter 图标集中在 [`NodeLaneIcons`](../lib/theme/nodelane_icons.dart)，使用已有 `CupertinoIcons`；iOS 原生底栏使用 UIKit SF Symbols。品牌标识共用 `NodeLaneBrandMark`，来源与许可见[品牌素材](design/nodelane-brand-assets.md)及[第三方声明](../THIRD_PARTY.md)。

## 共享组件

常规控件位于 [`nodelane_controls.dart`](../lib/modules/widgets/nodelane_controls.dart)，主题由 `nodeLaneModalTheme` 提供。

| 职责 | 入口 |
| --- | --- |
| 表面与分组 | `NodeLaneSurface`、`NodeLaneGroupSurface`、`NodeLaneGroupDivider`、`NodeLaneGlassSurface` |
| 标题与导航 | `NodeLanePageHeading`、`NodeLaneSectionHeading`、`NodeLaneCatalogHeading`、`NodeLaneBubbleHeading`、`nodeLaneAppBar`、`NodeLanePinnedHeader` |
| 输入 | `NodeLaneTextField`，搜索使用 `.search` 配置 |
| 操作 | `NodeLaneIconButton`、`NodeLaneMenuButton`、`NodeLaneCloseButton`、`NodeLaneToolbarAction`、`NodeLaneSecondaryButton`；主按钮沿用共享主题的 Flutter 按钮 |
| 设置 | `NodeLaneRow`／`.card`、`NodeLaneSwitchRow`、`NodeLaneDisclosure`、`MobileSettingsChoice` |
| 选择与数值 | `showSettingChoice`、`showSettingText`、`NodeLaneNumberRow`／`NodeLaneNumberButton`；页内复用 `NodeLaneOptionSwitch`、`NodeLaneSegments`、`NodeLaneTabSegments`、`NodeLaneChoiceRow`、`NodeLaneSwitch`、`NodeLaneSliderRow` |
| 卡片与标记 | `NodeLaneChoiceCard`、`NodeLaneCoverBadge`；业务卡片组合这些控件 |
| 模态 | `showNodeLaneBubble`（锚定气泡）、`NodeLaneBubbleFlow`（逐级返回）、`NodeLaneBubblePanel`、`NodeLaneConfirmPanel`；通用对话框复用 `NodeLaneAlertDialog`、`NodeLaneModalActions` |
| 状态 | `NodeLaneNotice`／`showNodeLaneNotice`、`NodeLaneEmptyState`、`NodeLaneSkeleton`、`NodeLaneProgress` |
| 批量选择 | `nodeLaneSelectionAppBar`、`NodeLaneSelectionBar` |

- **输入**：名称放在框上方，单字段表单不重复弹层标题；URL、邮箱、名称、密码单行横向输入，正文／代码才换行。清空和显隐在框内，框外点击或滑动收键盘并保留关键词；取消与保存空值分别处理。
- **界面文案**：控件显示名称与当前值，不另写功能介绍或操作教程。空态显示结果和可用操作；输入格式、权限要求、错误原因、破坏性操作的影响及读屏标签保留。
- **设置行**：名称左、值右。进入设置分类用前进箭头，选值或编辑用向下箭头并在行旁弹出气泡。单选后只收起顶层；数值可连续调节，拖动松手保存。文本确认才保存，开关整行或控件点击都只提交一次。
- **选择**：需要确认的多选和文本编辑保留本地草稿，搜索不丢失隐藏选择。目录筛选即时生效；滑块通常松手提交，外观缩放保留实时预览。
- **浮动数字**：从当前控件位置浮出，宽 184、三行、行高至少 44；停止滚动才保存，外部点击关闭，外部值刷新不触发写入。范围仍由业务定义。
- **气泡顶栏**：`NodeLaneBubblePanel` 固定顶栏，正文按需滚动。`NodeLaneBubbleAction` 提供关闭、返回、管理、完成、重置和清空；页面可传入专用按钮、标题内容和副标题。独立气泡显示关闭，原气泡内的步骤显示返回。`onDismiss` 可回传结果，`dismissEnabled: false` 同时禁用默认按钮、系统返回和点外关闭。
- **模态**：短内容随内容展开，避让键盘及安全区。底部双操作窄屏纵排，三操作纵排。嵌套返回只关闭当前层，草稿与滚动由所属页面管理。
- **异步操作**：处理中防重入，写入失败保留草稿或提示核对可能的部分结果；结果未知时不自动重放。控制器、订阅和临时状态随所属视图释放，迟到回调不得改写新页面。
- **折叠**：`NodeLaneDisclosure` 管理展开动画和状态，收起后释放隐藏内容；每次重新展开创建新的单订阅流。`NodeLaneRevealScope` 只在搜索直达时定位，开关、清理等动作不自动执行。
- **页面动效**：[`NodeLaneMotion`](../lib/theme/nodelane_motion.dart) 统一时长、曲线和减少动态效果。全页用 `MaterialPage`／`MaterialPageRoute` 保留系统返回手势；对话框用 `showNodeLaneDialog`，锚定气泡只缩放、淡入自身。同页用 `NodeLaneContentMotion(value: 目的地, ...)` 仅平移当前内容；首次切换才创建动画控制器，相同目的地的数据刷新不重播。可横滑页签用 `TabBarView`；点选后原位替换的页签用 `NodeLaneMotion.tabBody` 复用页签控制器。
- **分栏与资源**：来源浏览向下追加内容时保留父列表的高度和滚动状态。离屏行暂停动画并退出键盘焦点遍历；收回一层即释放该层。目录收窄时仅额外保留返回位置已挂载的卡片，内存压力下释放。后台主导航分支同样暂停动画并排除焦点，TV 只挂载当前分支。
- **加载与失败**：请求空态用 `NodeLaneEmptyState.loading/error`，内容骨架用 `NodeLaneSkeleton`；短屏／大字号可滚动，保留业务原有重试和电视焦点。

### 通知与反馈

`NodeLaneNotice` 共用轻提示、结果、错误和进度内容；浮动入口为 `showNodeLaneNotice`，BotToast 只承担宿主、计时和路由生命周期。`toastError` 负责错误整理与记录。

- 轻提示默认 3 秒、错误 6 秒、带操作结果 8 秒；支持关闭或横滑。同一任务通过 `NodeLaneNoticeHandle` 原位更新，旧任务只能关闭自己的提示。
- `NodeLaneNoticeAvoidance` 测量底栏、工具栏、键盘与安全区，浮层上方避让操作区并留 12 间距。路由或根标签切换收起旧提示，关闭提示不取消任务。
- 状态使用共享文字和语义色；长说明、操作换行，进度条高 3。业务动作仍由调用方管理，后台自动更新保持安静。

### APP 反馈与新增来源申请

- **更多 → 关于与帮助 → APP 反馈** 用于反馈应用问题；在 **来源 → 管理 → 申请新增来源** 可推荐网站。浏览器开始页与网页菜单也能发起同一份申请。
- 两类入口共用 `SupportRequestPage`。新增来源先填写网站名称和地址，表单所在栏够宽时两项并排；补充说明和联系信息选填，提交按钮位于键盘上方。网页发起只预填域名与首页，不读取网页标题、路径、查询参数、片段或登录信息。
- 匿名调用现有 `POST /v1/support-requests`：来源使用 `kind=website`；APP 沿用后端通用 `kind=plugin`，内容前缀为 `[NodeLane App]` 与实际安装版本。字段长度遵循接口的名称 100、地址 2048、内容 1000、联系信息 200 字符约束，App 标识和版本计入内容长度。API 根地址与官方服务共用 `NODELANE_API_BASE`，不依赖翻译账号。
- 显式提交时先将内容和 UUID 请求编号写入设备私有安全存储，两类草稿分开。提交期间禁用重复操作；网络失败或结果未知时保留原内容和编号，返回再打开或重启后可用相同 `Idempotency-Key` 重试确认。明确拒绝可修改后重试，成功展示后端回执；“继续反馈”清理上一份记录。从来源目录发起的未提交编辑仅保留在该目录的内存中；可先返回查仓库，再打开申请接着填。
- 客户端不自动重试、不携带来源 Cookie 或账号凭据；离页释放连接，迟到回调不修改页面。存储读取失败时提供重试，不能覆盖未读取的记录。现有诊断错误报告仍使用下述 GitHub 问题流程。

## 导航与书架

默认底部入口为书架、更新、来源、浏览器、更多。点媒体按钮在锚定气泡中切换漫画／小说／动画；气泡只列可见媒体，保留当前勾选与更新角标，只有一种媒体时不弹出。iOS 使用一个 `UITabBarController`，Android 使用 `NodeLaneFlutterTabBar`。Android 胶囊底栏高至少 64、左右留白 16，外壳只绘制一层玻璃；选中背景包含图标与标签，大字号增高并避让手势区。

书架、更新、来源根页从媒体菜单与操作开始，浏览器从书签、标签、更多和搜索框开始，更多从账号摘要与搜索开始。二级页复用居中紧凑顶栏，阅读器与网页不显示应用根底栏。隐藏媒体、导航顺序和角标沿用偏好；阅读历史用于恢复、统计和备份，没有独立入口，网页历史见浏览器一节。

- 书架顶栏放媒体切换、更新／停止、导入、筛选和更多，下方是居中的搜索框。导入、筛选／排序／显示与更多操作使用锚定气泡；选择来源后仍回到原筛选位置。种子、批量设置分类和移除确认使用可返回的表单。批量栏保留常用操作，「更多」从按钮上方展开。
- 书架切媒体由主导航转场，切分类由页签滑动；切换网格／列表、空态和选择模式仅移动结果区或顶栏。打开详情、续读和批量迁移沿用页面转场；批量迁移只在匹配、复核、写入与结果之间过渡，逐本进度不重播。
- 漫画目录、小说阅读设置和动画播放设置从工具按钮展开气泡，漫画图片操作从实际长按位置展开。翻页、横滑和播放手势沿用各自设置；经典书架的可拖动设置面板按已挂载的页签内容定高。
- 只展示有作品的可见分类，分类是否出现按搜索前的书架判断。窄屏横滑切换，宽屏左栏独立滚动、右栏展示作品；唯一的「全部」不占分类栏。计数和随机打开使用当前筛选结果；全选、反选只改变当前分类和筛选范围内的作品，保留范围外的选择。
- 分类管理留在原书架／详情气泡；从其他表单或「更多」进入时显示弹窗。面板只列入口媒体的分类（包括空分类和隐藏项）。「更多」和底部书架按钮都沿用最近访问的书架；未访问过或该书架已隐藏，就按当前导航顺序取第一个可见书架。拖动排序，点名称原位展开重命名、可见性、更新和删除；[名称输入卡](images/android-category-name-card.webp)随输入预览书签，确认才写入，取消保留原选择。
- 四种显示模式由 `MobileBookshelfCard` 绘制。常规手机舒适两列、紧凑／仅封面三列，随屏宽与字体缩放调整；手机不读取每行列数，桌面／电视和来源保留各自偏好。
- 网格封面比例 1:1.08、圆角 10，书名最多两行，身份单行；列表缩略图 64×92。未读与下载标记分列封面顶部，零值隐藏，超过 999 显示 999+，读屏保留真实数量。
- 本地作品只显示一次本地身份，在线作品按偏好显示来源／语言。续读使用共享圆形按钮，独立于卡片命中；多选隐藏徽章与续读，显示选择圈。
- 未读完恢复原进度，全部已读仍可从阅读顺序中的首章首屏打开，不清空阅读记录。长按作品或在「更多」中点「选择作品」进入多选。
- [书架筛选](images/android-bookshelf-filter-options.webp)与章节设置共用页签和「不限／包含／排除」选项组，窄屏或大字自动换行。筛选、排序、显示即时保存且各自保持位置；排序条件与方向分开。来源筛选使用可搜索草稿，确认时过滤失效来源。
- 空库引导浏览对应媒体来源或本地导入；无搜索结果提供清空与调整筛选，不能把分类无结果显示为空库。
- 书架导入、空书架的导入按钮及本地详情的添加章节使用同一个导入气泡。点「选择文件」进入系统选择器；漫画 ZIP／CBZ、小说 EPUB、动画原视频格式。取消选择后仍可在原气泡重选，保留 EPUB 拆章选项；处理中防重复，未知写入结果提示先核对。
- 批量分类取原对象分类并集，保存前重读记录、过滤失效分类；已收藏单本保留隐藏分类。移除书架记录和下载文件独立选择、默认不选，取消保留选择，失败提示核对部分结果。

### Android 平板

触屏窗口短边达到 600 dp 时，根导航把同一组胶囊按钮排到起始侧；窄分屏及横屏手机使用底栏。Android 的系统分屏允许本应用与另一个应用并排，系统分隔条调节各自窗口。窗口内的左右栏由 Flutter 根据扣除导航和安全区后的内容宽度排列，字号变大时需要更多宽度。颜色、图标、文字、玻璃和卡片均取手机组件。

| 页面 | 宽屏用法 |
| --- | --- |
| 书架、更新、追踪 | 书架分类与作品分栏，搜索框居中收窄。更新让媒体选择与时间线并排；追踪将服务与搜索放在结果旁。 |
| 来源与搜索 | 网站目录和跨站结果优先双列，搜索工具在上方。进入网站后目录与站内作品并排，作品详情在下方展开。见[来源与搜索](#来源与搜索)。 |
| 作品与阅读 | 详情按实际可用宽度显示一至三栏，目录工具固定在章节上方。漫画阅读器将进度与操作并排放在底部，不改变画面尺寸。 |
| 浏览器 | 宽屏首页左栏是全部常用网站，右栏从续读开始、下接最近访问。网页工具可排进地址栏，窗口收窄后移到底栏；两种布局使用相同按钮、气泡和网页实例。 |
| 更多与工具 | [「更多」左栏](images/android-tablet-more.webp)为账号、搜索、工具与关于，右栏为设置分类或搜索结果；进入设置后使用[分类与详情双栏](#更多与设置)。日历和当日作品并排；欢迎页将标题与当前选项并排。 |

### 更新与诊断

更新按日期连续分组、逐条懒构建。手机和平板的顶栏提供[下载队列](#下载队列)，有待处理任务时显示数量，返回保留当前媒体与查询。刷新／停止直达，清空放更多菜单并确认；封面进入详情，正文阅读章节，下载操作独立。任务由应用级 Provider 容器持有，离页可继续，进度与失败入口使用统一通知。

更新错误保留书名、摘要及详情，迁移／忽略独立；作品不存在时只提供忽略。诊断错误报告可查看时间、次数、堆栈或复制内容；从报告打开的 GitHub 问题草稿由用户审核后提交。

### 欢迎引导

手机使用两步：品牌与媒体选择，然后浏览来源、本地导入及可展开的第三方来源库；至少选择一种媒体，允许暂时跳过。恢复备份独立显示。浏览来源按所选媒体打开现有目录，添加来源库后可进入对应安装分区。

目录预览只显示已有文件夹、数量和按需展开的最多 40 个名称；失败与空目录分别提示。选择、扫描、恢复和添加期间禁止重复发起或切步；返回先处理内层恢复弹窗。目录选择取消直接返回，草稿按当前媒体保留。

## 来源与搜索

MuMu 运行截图：[目录筛选气泡](images/android-tablet-source-filters.webp)、[目录与站内作品](images/android-tablet-source-website.webp)、[来源设置气泡](images/android-source-settings-bubble.webp)、[搜作品](images/android-tablet-source-search.webp)、[新增来源表单](images/android-tablet-source-request.webp)。安装、同步频率、来源身份和宿主执行边界见[来源插件](SOURCE_PLUGINS.md)。

- 官方／第三方分区共用 `SourceWebsiteCard`；常用位于首个可见分组，其余目录不重复列出。长按网站在手指旁选固定、最新内容、原网页、说明或设置。点分类数量直接看完整资料。
- 网站卡片显示名称、语言、分类、收费底带及独立 18+ 切角。标准字号高 136，随窄屏／大字号统一增高；操作位承载安装、更新、重试和常用管理。缺资料保持未标注，成人标记只读取 `isNsfw`。
- 「NodeLane／第三方」只切换目录。「管理」气泡内可查看、刷新仓库，切换可见性或添加仓库；地址识别、去重与错误重试保留在当前步骤。批量操作直接作用于目录，创建扩展只在开发者模式提供。官方网站缺失插件时优先安装；第三方安装／更新失败保留旧版本。
- 网站图标复用 `NodeLaneWebsiteIcon` 与现有网络图片分支的 30 天磁盘缓存，空地址／失败显示占位，不自动发现 favicon。
- 目录收窄到侧栏宽度时，搜索框在工具区下方独占一行，与卡片两侧对齐；媒体、管理、分区切换和筛选在上方按可用空间换行。宽目录的筛选和管理仍在搜索框旁。
- 筛选按钮显示结果数，有条件时加圆点。点它打开气泡，按语言、地区、形式、创作或收费筛选，点选立即更新目录与计数。同组选项取并集，不同组取交集。条件摘要与「清空」在气泡内；清空恢复默认语言和无分类限制，保留关键词。关键词和筛选按媒体、官方／第三方分别记忆。
- 手机横竖屏都以单列显示网站；点网站整页进入站内作品，再点封面整页进入详情。系统或标题栏返回键逐级回到原列表，保留草稿、筛选和滚动位置。
- 平板宽度够时首页卡片两列，点网站后目录与站内作品并排；放不下时站内作品接在目录下方。点封面在下一行展开详情，父列表不缩短。沿标题栏向下拖可回看上层，列表内仍可滚动和下拉刷新；返回收起当前层。
- 跨来源搜索仅选择已安装且允许显示的来源。来源详情按身份、动态设置、高级操作排列；Cookie、卸载和开发者工具保留原确认及条件。

### 跨来源与站内搜索

- 「搜作品」、目录空态和键盘提交携带同一关键词。关键词、搜索范围和进度入口共用结果上方的工具栏，窄屏或大字号时换行。空词提示输入，编辑草稿保留上次提交的结果。
- 只展示有命中的网站。手机每个网站分组占满一行；「查看全部」用已提交的关键词打开独立站内页，直接点封面则打开独立详情，返回保留跨站搜索草稿与结果位置。平板宽屏可并排两个分组，站内结果在旁边或下方展开并共用顶部输入框，详情在结果下展开。范围和进度在各自气泡内操作；全部／常用／自选即时生效，保留未改变来源的请求和横向位置。重试只重跑失败的网站。
- 全局与迁移搜索共用 `SourceResultSection`、`SourceResultCover`、`GlobalSearchResultCard` 和三路 `FetchGate`。查询变更、离页释放订阅，迟到结果按轮次丢弃；查看全部复用关键词与首屏。
- 站内热门／最新首次访问才请求，各自保持分页、在途读取和位置；搜索或筛选使用一份可替换结果集，首屏、分页与重试共用参数。下拉刷新失败保留内容，隐藏列表不主动翻页。
- 站内 `…` 的「已保存搜索」「网站说明」「来源设置」和「网页翻译」共用锚点动效与固定顶栏，从各自的操作行弹出，关闭后回到原菜单。目录卡片直开说明则返回卡片。只有已提交的关键词可保存；搜索按来源隔离，管理时才显示删除，点选关键词直接回到结果。卸载来源后同时收起失效的菜单。
- 插件筛选、排序、三态和开关点选即查；文本停顿 300 ms 合并查询，离开气泡仍应用最后输入。每次请求独立持有一份条件；恢复默认时，有关键词则继续按词搜索，否则回到原浏览标签及位置。长选项可在气泡内搜索，展示翻译不改变插件参数。
- 来源偏好单选、开关及多选逐次保存，写入失败保留原值。名称、地址等文本确认后才写入；删除仓库、卸载来源仍显式确认。
- 结果懒构建、封面复用原缓存，空封面显示本地占位。站内页面最多保留两份浏览列表和一份搜索结果，离页释放；跨来源仍可能同时挂载所有来源首屏，尚无全局可见图片窗口。

**独立页面与单栏例外**

| 原网页、阅读器与播放器 | 原网页需要完整 WebView、登录与网页历史；章节阅读和播放需要独立视口与手势。返回后继续当前作品。 |

### 迁移与批量迁移

单次迁移先显示当前作品、目标和可折叠章节，确认／取消固定可达；读取失败可重试，写入失败提示可能部分完成，不自动重放。追踪添加在同页选分类，提交时过滤失效项。

批量迁移按原来源、选作品、目标来源、匹配复核四步进行。逐本匹配保留两秒间隔；更换候选在气泡内搜索，读取期间不能开始迁移，失败项不进入执行。确认继续调用原服务，结束显示迁移／跳过／失败及待核对项，不建立另一套事务或后台恢复状态。

## 漫画详情与阅读

- 窄屏将作品卡、资料与章节放在同一滚动页。双栏左侧是作品与资料，右侧是章节；来源内展开的详情最多两栏。独立详情足够宽时可将简介／题材与快捷操作移到第三栏。切换栏数保持可见章节。
- 点封面查看、点书名搜索、长按复制。没有简介或题材时不显示空区；网页、追踪、日历、推荐、关联作品或本地编辑按实际能力直接排列，不再藏在折叠区。
- 刷新保留已有详情与章节，只为缺失区域显示骨架；等待目录时不显示零章节或无结果，收藏仍可用。阅读入口由 `MobileReaderEntryState` 保留封面、书名和章节，失败重试共用原请求。
- [作品更多](images/android-detail-tool-more.webp)上排是刷新、分享、导出，下方是该作品可用的管理项。分类管理和迁移在同一气泡内逐步操作；扩展设置和偏好选值各自从触发行弹出。分享和导出目录使用系统选择器。
- 固定目录栏在章节数量旁放[下载](images/android-detail-tool-download.webp)或本地添加，另一端放[章节设置](images/android-detail-tool-settings.webp)，两个触控区域至少相隔 24 dp。下载可取接下来的 1／5／10／25 章、未读或全部，范围取当前筛选结果。
- 章节设置按「筛选／排序／设置」切换。不限／包含／排除、排序字段和方向、左右滑动动作共用带勾的单选卡。滑动方向标题独占一行，四个动作最多两列，气泡变窄或字号增大时按最长标签减少列数。筛选和排序只影响当前作品，滑动习惯对所有书籍即时生效。翻译组在气泡内搜索，确认时核对仍存在的组。
- 章节卡按需构建，正文、下载与长按选择保留独立命中区域，按章节 ID 保持选择。
- 书架与章节共用批量栏，取消、数量、全选／反选和底部常用动作明确可达。下载／删除按原条件提供；本地删除章节保留原包，在线删除只清理下载，本地目录确实为空才移除漫画。
- 删除确认固定对象范围，完整名单可滚动；处理中防重入和返回，取消保留选择，失败提示核对。写入按最新记录合并，不能重建已删除记录或覆盖期间更新的进度。
- 工具栏叠放而不挤压阅读画面；底部为章节、原图／译图、阅读，上方为返回、书名／章节、书签和更多。隐藏工具栏释放焦点，短屏和大字号可滚动，页码与自动滚动按钮避让安全区。
- 阅读设置、作用范围与位置锚点见[阅读设置](design/reader-settings-redesign/design.md)。设置面板不持有来源、翻译任务或图片缓存。

### 漫画加载与资源调度

- 打开目录与连续跨章共用 `getChapterPages`，依次读本地／下载副本、章节清单缓存、来源结果。清单保留重复 URL、headers、文件名与图片处理参数，旧缓存缺参数需刷新章节。
- 连续阅读按图片顺序接入相邻章，章首使用紧凑标签；章首／章尾区分加载、失败、空图片和目录边界，每方向最多一个请求。失败原地重试，普通滚动不循环重试。
- 上一章前插等待滚动停止，按章节、原图序号、裁切区域及图内偏移恢复；尺寸缓存随页移动，恢复时临时保活锚点图。后台结果等前台再提交，迟到结果和淘汰后重复章被拒绝。
- 进度按实际可见原图发布，位置校正不额外触发章节变更或资源调度。前插、图片变高和设置重排共用锚点流程；用户开始手势、翻页或自动滚动后解除定位。
- `ReaderContentStatus` 统一图片与章尾状态，保留已知尺寸或估算占位；错误可滚动、可重试，成功不留下过渡空白。
- 原生阅读窗口从首张可见原图起覆盖当前＋后六张；拆页只计一次，跳过过渡页，短图同屏超过七张时优先覆盖全部可见图。章末进度与窗口独立。首帧前启动预取，翻页、可见范围或章节清单变化即补齐；到列表末端不足六张继续取相邻章，失败保留显式重试。
- 原图预取最多三任务在途，顺读另留前两张，倒读优先补前三张，后六张不缩减。窗口内成功文件不被自动磁盘淘汰，离窗或后台解除保留；已开始的共享下载可结束。此预算不覆盖控件和翻译的独立请求。静态位图由控件与 Flutter 图片缓存管理，章节模型不持有解码副本。压缩包原图由当前、相邻及窗口涉及的章节保留；回看时同一章的并发读取共用一次恢复。章节清单无有效期，签名地址失效需刷新。
- 来源限流／验证码、Cookie、代理／DNS、TLS 与地址有效期均可能导致失败。普通图片和第三方来源的截止时间、取消及 provider `timeLimit` 尚待统一；官方文本桥的 30 秒限制按请求／响应流阶段执行。

### 阅读目录与图片操作

目录从当前筛选／排序取得一次快照，按章节名或翻译组搜索；定位当前章先清词并按章节 ID 定位，不估算像素。选择当前章只关闭，选择其他章前核验记录及阅读器身份；书签通过原写入队列修改最新记录。

长按图片提供保存、分享、设为封面，明确作用于原始整页，不含译图、拆页或滤镜；图片信息取自身章节。字节复用本地／压缩包／缓存，同次只读一次，失败可显式重试。iOS 保存到应用存储位置的 Pictures，Android 保存到 Pictures/nodelane-comics。设封面沿用小于 5 MB 的既有限制，只限制该动作。保存成功禁用重复保存，分享取消不算发送成功。

## 多标签浏览器

手机和平板共用 [`showNodeLaneBubble`](../lib/modules/widgets/nodelane_bubble.dart)：按内容高度和可用空间定位。优先在按钮上方或下方展开；长列表上下放不下时排在按钮旁，窄屏两侧也放不下则居中，不画误导性的尖角。保留输入焦点的菜单始终避开原输入框，所有气泡避让键盘和系统安全区。点外侧、关闭或系统返回均可退出；减少动态效果时直接显示。只绘制气泡转场，不截图或复制网页。

Android 8+ 的 ARM／x86_64 进程使用 GeckoView 和随包 uBlock Origin。盾牌显示当前页被拦截的**请求数**，超过 99 显示 `99+`，暂停时显示暂停标记。点盾牌打开「广告过滤」：网页就绪后读取本站开关和本页／累计计数，扩展徽标变化合并读取，换页不沿用旧值。状态未确认时提示重新读取，不显示推测的开关或数字，也不重放上次切换。高级工具仍可展开；切换后只有明确选择「刷新并返回网页」才重载。

Android 7／32 位 x86 和 iOS 沿用系统 WebView。标签记录、历史、书签共用原存储；Gecko 有独立网站登录，升级后可能需重新登录。来源验证入口沿用来源原有会话。

- 开始页与空标签共用 `MobileBrowserStartPage`。常用网站、继续读、最近访问有条目才显示，空分区不占位。宽屏搜索框居中收窄；左栏是全部已固定、可见且网址不重复的网站，可独立滑动，不显示滚动条。右栏先续读后最近访问，按栏宽、剩余高度和字号排整行续读卡，最近访问略过已显示的网址。仅一栏有内容时用全宽，窄屏按单列排布。「查看全部」打开续读列表；历史与续读完全重合时仍能从「更多」打开历史。空标签不创建 WebView。
- 开始页和网页共用地址框。已开标签、书签、历史在本地立即匹配；普通搜索词停止输入片刻后，才发给当前选择的 Google、Bing、百度、DuckDuckGo、Yahoo 或搜狗取联想词。网址、带凭据的输入、未确认的输入法组合文本不作联想请求。点联想词只回填并将光标放到末尾，仍可编辑，提交才搜索；点本地结果直接打开。切换引擎保留草稿及选区，只显示新引擎的结果；网络失败仍可输入与提交。
- **书签**是手动收藏的网址，**继续读**是独立的浏览器阅读进度。前台网页被识别为章节且有阅读位置后自动记录；普通网页只进历史。相同章节 URL 更新一条进度，不必收藏。移除续读不会取消收藏，取消收藏、清空访问历史或关闭标签也不会移除续读。旧版带位置的书签仍可从原先位置打开，其既有进度可在续读中独立更新。
- **夹在这里**立即更新当前网页的续读位置和截图，不添加书签。自动记录在首次取得进度时尝试保存预览，后续滚动只更新位置。首页和气泡的续读卡在相同字号下等高，标题预留两行，显示域名、网站明确给出的页码和相对时间。图内百分比仅用于恢复，无图片锚点时按滚动坐标恢复。截图保存在设备私有、排除备份的目录，最后一个引用移除后清理。截图失败不影响位置恢复。
- `BrowserLibraryStore` 将续读与访问历史、书签分别保存在设备私有安全存储中。访问历史按本地日期与 URL 去重，最多 500 条；书签按 URL 去重。进度更新不重写历史与书签。串行写入成功后更新界面，读取／写入失败可重试。
- **专注阅读**：在主页面的可见图片或 Canvas 附近识别章节。明确的正文容器可直接识别；否则需有章节网址、标题或同源下一话链接，并按视口短边判断单页宽度，兼容横屏双页。从网页「更多 → 专注阅读」进入，网页延伸至底边。轻点页面中央，[紧凑工具条](images/android-browser-focus-tools.webp)从底部居中浮入；可原位切图、夹页、退出，临近章末且下一话同源链接唯一时提供「下一话」。切图时工具条保持打开；点外侧、关闭或滚动网页会收起，不占正文空间。系统返回先收起工具，再退出专注。网页更多菜单只有在已安装漫画来源的永久 ID 与本地作品／章节 URL 唯一匹配时才提供「用 App 阅读器打开」；作品进详情，章节进阅读器。
- 最近访问、历史和书签使用同一网站图标：取自 DOM 或同源 `/favicon.ico`，不调用第三方服务。相同 URL 共用请求和图片缓存；失败后一分钟内使用占位。记录访问与有无图标无关。
- 历史、书签和续读气泡共用 `BrowserLibraryPanel`：标题和关闭按钮固定，搜索框与列表在下方滚动。各自可搜索标题／URL、选择和移除；只有历史按日期分组并提供清空确认。
- 顶部叉号离开网页；工具栏后退、系统返回以及菜单前进优先使用原生导航历史。只在原生方向不可用时，按保留的 URL 重建。地址栏加载中可停止，否则可刷新。更多菜单含书签、分享、查找、复制及系统浏览器；页内查找独立于翻译，关闭后清空匹配。
- 网页工具包括后退、切图、翻译设置、新建和标签。常驻工具栏和专注浮条使用浏览器的单行切图按钮，图标旁显示当前的「原图」或「译图」，译图用强调色。操作行高 44 dp，底部安全区另计；点按切换不改变按钮或网页的大小。「网页翻译」气泡提供自动翻译、语言、模型与渠道，不重复放置显示切换。翻译语言在翻译设置上叠加选择气泡。Android 长按链接可在触点旁选择后台打开，当前页不切换；图片本身有翻译操作时优先显示图片工具。
- 标签气泡显示 **20 个逻辑标签**以内的缩略图列表，标明当前页；点行切换，关闭键独立。可撤销最近一次关闭，恢复 URL、逻辑历史与阅读位置。关闭最后一张补空标签，撤销时不多留占位页。
- `BrowserWebViewCache` 以原生 keep-alive 保留最近 3 个网页。网页路由内同时保留这 3 页的显示视图，仅当前页绘制、接收焦点和运行 Flutter 动画；切换复用控制器和翻译桥，不重挂原生视图或重设滚动位置。切标签或回开始页不按时间销毁，命中缓存保留 DOM、表单、JS 和滚动状态。超过容量按最近选择顺序 LRU 回收旧页，系统内存警告卸载并释放后台页，关闭标签显式释放；后台暂停媒体、Android 绘制和翻译资源。
- 标签总览立即打开，截图异步更新、同页截图不并发。切换不等待 JS 锚点；离开网页保存阅读位置，但不等待缩略图。网页就绪后只淡出预览，系统减少动态效果时取消淡出。
- 回收页及应用重启后按 URL、滚动坐标和阅读锚点重新加载恢复，未提交表单和 JS 运行状态不持久化。元数据串行写入，隐藏回调与迟到锚点不覆盖位置；预览仅驻内存，每张最多 384 KiB、最多 12 张，关闭释放。
- 主框架失败提供重试与编辑，渲染器失效时改址或重试会重建会话。盾牌可清除当前 Gecko 站点的 Cookie／HTTP 认证，不清其他站点或来源会话；菜单另有明确的全局 Cookie 清除。两者都需要确认，均不等同清除站点 localStorage。
- iOS 新窗口在导航回调转交标签入口并取消原跳转，Android 沿用原新窗口入口。图片发现、归档、原译图显示和任务生命周期见[翻译架构](TRANSLATION_ARCHITECTURE.md)。

### 下载队列

`MobileDownloadQueue` 组合原 `DownloadQueueScreen` 的订阅与回调：进度、拖动排序、开始／重试队列、取消单章或整部排队章节，以及设置入口。拖动区与菜单独立，底部操作可达；返回菜单选择后重新核实任务是否仍待处理。进度只使用服务已有数据。

### 小说与听书

小说工具栏提供章节进度、前后章、目录、字号、听书和设置；控件叠放且隐藏后释放焦点。字号使用 8–40 数值气泡；连续进度读取实际控制器范围，模式、分页和阅读记录沿用原服务。

阅读内与全局小说设置复用字体、主题、排版与颜色；页边距 0–50、行高 1.0–3.0，松手保存。单本模式在阅读内设置，全局保留自动双页偏好。听书播放器身份稳定，停止不因等待或失败禁用，关闭后的迟到初始化不开始朗读。

听书语速 0.1–1.0（两倍显示）、音调 0.5–2.0，语言来自设备列表；缺失语言保留原选择。先存偏好再调用引擎，失败显式重试；默认语言只清空偏好，不保证立即重置已初始化引擎。

### 播放器与字幕

播放器设置保留内部播放器、音频、解码、自定义按钮和 MPV 入口。AniSkip 开关与展开独立；音轨语言保存自由文本，音量增强 0–200 松手保存；解码模式保留 rawValue，不以界面选中代表设备支持。

手机与桌面共用锚定的播放设置气泡，标题与返回固定；从设置首页选值后回到原列表位置，从快捷入口选值后关闭。电视保留遥控侧栏。画质、轨道、章节、倍速等由播放器生成；外部偏好刷新不覆盖正在编辑的输入。

自定义按钮保存名称、点击／长按／启动代码，编辑页不执行代码。MPV“恢复内置配置”从安装包恢复同名文件，独立于启用开关，失败保留显式重试。

在线字幕入口为“播放器 → 内部播放器 → 在线字幕服务”，默认关闭：

- 可选个人 Wyzie Key 或自有完整 HTTPS 服务，关闭保存清除配置；凭据使用设备安全存储，不进入备份或默认日志。
- 自有服务遵循 [Wyzie 契约](https://docs.wyzie.io/subs/usage/direct)：GET 查询包含 IMDb `id`、`encoding=utf-8`，剧集增加 `season`／`episode`；返回含 `url`、`media`、`language`、`display`、`format` 的数组。下载为 UTF-8 文本，支持 SRT／ASS／SSA／VTT／SUB／TXT。
- 服务地址不带查询、片段或内嵌凭据；同源下载可带服务令牌，跨域只使用响应的签名链接，不自动跟随重定向。
- `SubtitleCatalog` 管作品发现，`SubtitleSource` 管搜索和读取，播放器仅接收字幕文本。配置变化、关闭或离页销毁旧请求和结果；30 秒超时、元数据 2 MiB／字幕 8 MiB 是现有边界。
- NodeLane 云端个人字幕凭据接口、刷新与撤销尚未实现，不提供空来源选项。真实 IMDb／Wyzie／自有服务、原生播放及下载目录仍待验收。

### 同步与追踪

同步仅提供用户填写地址的自建服务，须实现 OAuth PKCE、`/api/version`、`/api/sync/v1` 并登记回调。关闭同步沿用原频率规则；单向上传／下载确认后重查登录和运行状态。

追踪账号按服务 ID 隔离，登录／退出明确操作，点击名称进入详情。条目编辑复制当前记录，异常先刷新再继续，取消／同值不提交；原首次刷新可能补建远端条目，不能视为纯读取。移除关联不删除远端条目。搜索仅显式提交，迟到结果不改写已退出界面。

Kitsu 表单仅裁剪邮箱首尾空格、密码原样传递；密码默认隐藏，失败保留草稿，取消不保存自动填充。可选追踪书库仍使用共享大标题、搜索和服务切换，分组身份包含服务、媒体、关键词及刷新代次。

## 翻译与账号设置

- 阅读器通过“阅读 → 漫画翻译”进入设置；浏览器工具栏提供原图／译图和翻译气泡。阅读器和网页共用 `TranslationControlsContent` 和单图操作；两者与“更多 → 阅读与翻译”共用目标语言和翻译模型选择器。
- 首次显示原图，自动翻译默认开。前台同时显示译图且开关开启才自动送译；切回原图暂停新增工作，保留开关。关闭自动翻译仍可读缓存和手动操作。
- 原图／译图在工具栏切换。阅读器翻译面板只放设置；网页翻译面板另显示当前窗口的完成进度。失败原因和恢复操作留在对应图片上。
- `TranslationImageStatus` 在等待、处理中或异常时显示左上角标。失败可重试，状态未知可核实，译图读取失败可重新读取；成功、无文字及未送译时没有标记。额度不足时角标显示「额度不足 · 升级」，补足额度后可长按重试；重译也在长按菜单内。图内只给操作按钮让出阅读器手势。原生角标在滤镜外显示，网页用 Shadow DOM 隔离样式并核验文档和图片修订。
- 目标语言与界面语言共用 [17 种语言定义](../lib/l10n/languages.dart)，各自保存；`TranslationLanguageRow` 统一选择入口，取消／同值不写入。任务与缓存规则由[翻译服务](TRANSLATION_ARCHITECTURE.md)维护。
- 更多摘要打开 `MobileNodeLaneAccountPage`，显示账号名和一行套餐；未知套餐保留服务名称。详情显示 ID、订阅和免费／订阅／购买三类额度，未知、零和不限量分别表达。
- 账号读取 `GET /v1/me`、`GET /v1/billing/status`，共享快照和一次在途读取；失败保留同账号成功信息，换号／退出取消读取并清快照。「查看订阅方案」和「升级」共用[公开定价页入口](TRANSLATION_ARCHITECTURE.md#认证与设置)。「在官网管理」打开官网账户页，返回时刷新一次。

## 应用链接

各平台使用 `nodelane-comics` 协议，Windows 注册当前可执行文件，Linux 桌面入口传 `%u`。导入入口为 `nodelane-comics://add-repo` 与 `nodelane-comics://add-button`：

- 来源参数为 `repo_name`、`repo_url` 和可重复的 `manga_url`／`anime_url`／`novel_url`；按钮使用可重复的 Base64 JSON `button`。确认实际地址或代码后才写入。
- 拒绝凭据、端口、子路径和片段，登录回调不进入导入。仅确认／保存期间去重，完成、取消或失败释放；冷启动等首帧导航就绪再处理。

| 登录入口 | 回调与协议 |
| --- | --- |
| NodeLane | `nodelane-comics://nodelane-auth`，Native public client，PKCE／state 与系统安全存储 |
| AniList | `nodelane-comics://anilist-auth`，自有 Client ID `55972`，Implicit Grant、独立 state，不内置 Client Secret |
| MyAnimeList | `nodelane-comics://myanimelist-auth`，iOS／Android／Other 使用各自 Client ID，PKCE plain、独立 verifier 和 state |
| Simkl | `nodelane-comics://simkl-auth`，AUTH V2、S256 PKCE，核对 `iss=https://simkl.com` 和 `media:read media:write` |
| Trakt | 登录隐藏；缺少自有 Client ID 与 PKCE／HTTPS 回调，相关网络功能不可用，本地记录保留 |
| 自建同步 | 移动端 `nodelane-comics://oauth-callback`，桌面 `http://localhost:48765/callback`，由部署者登记 |

追踪凭据绑定服务与 Client ID，旧身份不复用。`TrackerOAuthBrowser` 在手机／macOS 使用系统会话，在 Windows／Linux 使用外部浏览器及协议监听；监听在完成、失败、释放或十分钟超时后取消，校验回调与唯一参数后保存账号。

Simkl 续期共用一次在途请求；401 先重读新令牌，必要时续期并最多重发一次，未知写入结果或网络错误不自动重放。明确失效才要求重新登录，切号／退出后的迟到结果不回写。真实授权的验证边界见文末。

## 备份、恢复与存储

- 默认文件目录：Android `/storage/emulated/0/nodelane-comics`、桌面 Documents/nodelane-comics、iOS 本应用 Documents。数据库名为 `nodelane-comics`；macOS 位于 Application Support/nodelane-comics/databases，Windows／Linux 位于默认目录的 databases，iOS 位于 Documents/databases，Android 使用应用私有目录。
- 本地来源使用当前配置目录；iOS 旧沙盒路径仅在当前 Documents／Library／tmp 中按相同相对路径核对，不按名称搜全盘。目录授权书签键为 `com.nodelane.comics.local_directory_bookmarks`。不读取、搬迁或删除上游旧数据库。

### 书架转场实测

同一台 MuMu（API 32、x86_64、横屏 1920×1080、密度 260）、同一本本地漫画和偏好，按「新版、基线、基线、新版」覆盖安装 Profile 包并冷启动。基线为 `74761201`，新版为统一筛选与分类面板的采样包，未包含导航监听清理。每次先走通路径、预热 4 轮，再采 6 轮；每个版本每条路径合计 12 轮。下表 P95 合并两批操作窗口内的 `Flutter.Frame` 原始帧计算；构建或光栅化任一阶段超过 16.67 ms 即计为超预算。内存是 `dumpsys meminfo` 主进程 PSS，每批比较预热后与第六轮返回起点后的读数。

| 场景 | 构建 P95（ms，前 → 后） | 光栅化 P95（ms，前 → 后） | 超预算帧／总帧（前 → 后） | 每批 PSS 变化（MiB，前 → 后） |
| --- | ---: | ---: | --- | --- |
| 书架：筛选 → 显示 → 关闭 | 0.97 → 0.94 | 17.00 → 16.69 | 129/878（14.7%）→ 48/881（5.4%） | +2.5、+2.5 → +2.7、+1.0 |
| 详情：更多 → 设置分类 → 管理分类 → 逐级返回 → 关闭 | 0.99 → 1.06 | 16.59 → 16.58 | 37/1016（3.6%）→ 34/1252（2.7%） | 0.0、−0.6 → −0.2、−0.2 |

这组模拟器样本中，两条路径的超预算帧占比都下降，详情构建 P95 略升。书架循环结束时主进程 PSS 由基线的 237.7–240.3 MiB 变为 252.7–255.3 MiB，详情由 247.4–249.4 MiB 变为 257.2–258.3 MiB。六轮内的增量不能代表长期内存上限。

新版书架和已打开的显示面板分别静置 3 秒，均记录到 0 个 Flutter 帧。MuMu 另验四种布局，以及本地漫画「详情 → 阅读器 → 章节目录」往返回到原书卡。关闭系统动画后，三种媒体可来回切换，详情分类逐级返回保留位置，本地导入连续两次取消系统选择器后仍能在原气泡重选。

组件回归另用 10,000 项懒加载网格检查切换期间没有额外内容构建、布局或卡片创建；检查气泡返回值、内层导航释放，以及经典面板停稳后没有待执行的动画帧。它们不替代真机帧耗时、长时间内存和 120 Hz 验收。
