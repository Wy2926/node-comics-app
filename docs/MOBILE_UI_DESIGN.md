# 手机界面与视觉令牌

iOS 与 Android 手机共用视觉令牌和基础控件；常规字号已在两端模拟器复核，Android 覆盖书架、来源、浏览器、更多及深浅色底栏。完整功能、真机与超大字号专项验收尚未完成，验证边界与待解决问题集中维护在文末。

保留漫画、小说、动画及现有功能，不按首版范围删减入口。手机共享视觉令牌、媒体切换和模态组件统一维护；功能变化以明确需求为准。

逐页替换手机视图，已落地书架、平台导航、浏览与来源管理、全局搜索、来源内漫画列表、迁移搜索与确认、批量迁移、扩展详情、更新、更新错误与错误报告、关于与应用更新入口、欢迎引导、漫画详情与目录、阅读工具栏与弹层、多标签浏览器、更多与设置入口、翻译与账号设置、外观及通用设置、安全设置与锁定页、下载设置与队列、浏览及扩展服务设置、全局漫画／小说阅读与听书设置、小说阅读内控件与听书面板、播放器通用／音频／解码设置、播放设置弹层、自定义按钮与 MPV 配置、同步与追踪设置、账号及条目管理、追踪编辑与搜索、备份／恢复与存储、回滚记录与来源维护、统计／分类／日历和导航定制。沿用现有来源、书库查询、筛选排序、导入、阅读、下载和批量管理逻辑。桌面与电视入口继续使用现有布局。后续页面按此文维护，不另建业务状态或迁移漫画数据。

## 视觉方向

参考 NodeLane 插件端书架的信息层级：大封面、来源与阅读状态、直接导入、搜索和批量操作。四个首批界面采用已选定的 [iOS 界面概念图](design/ios-interface-concept.png)：浅灰画布、白色分组、蓝色分段控件和清楚的标题层级。概念图是生成的设计参考，不是运行截图；实际封面、账号、功能与数据由应用提供。独立实现 Flutter/UIKit 视图，不复制同级 GPL 仓库源码或漫画封面。

| 令牌 | 手机约定 |
| --- | --- |
| 画布／表面 | 浅色近白纸面、深色炭灰；书籍封面保持原色 |
| 文字 | 沿用字体偏好；大标题 34、分组／面板标题 20、正文 16、书名／控件 15、次要信息 13、图注 12；遵循系统文字缩放 |
| 强调色 | 默认 NodeLane 蓝；继承已有用户主题的强调色，不改变状态色含义 |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24；手机页面边距 20 |
| 圆角 | 手机输入／分段／菜单使用 24 胶囊圆角，文字按钮使用胶囊形状、工具栏按钮使用圆形；封面 10、容器 18、模态外壳 24 |
| 图标与头像 | 常规图标 24、紧凑图标 20、账号头像 64；按语义复用同一套 Cupertino 图标 |
| 点击区 | 至少 44 pt；正文不压在封面上；长按继续批量选择 |
| 动效 | 短暂状态过渡；尊重减少动态效果，不新增常驻动画或整页模糊 |

### 基础组件与替换规则

手机页面只使用一套基础组件：

- `NodeLaneTextField` 同时处理普通表单与 `.search` 搜索配置，两者共用中性白色／石墨灰底、细灰边、局部轻阴影和 24 胶囊圆角。字段名称 17 置于输入框上方，间距 8；输入文字 16、框高至少 48、左右内边距 16，字段间距 16。名称不占输入宽度，点击名称仍可聚焦；URL、邮箱、名称和密码保持单行横向输入，多行正文才换行。输入区不再套独立分组底板；清空、密码显隐都在输入框内。搜索框在点击或滑动框外区域时收起键盘并保留关键词，点击框内清空按钮仍可继续输入。单字段编辑只保留一处框上方名称；代理、分类名称等居中表单去掉重复的弹层标题，辅助说明使用 14。键盘“下一项”连续填写，最后一项“完成”仍调用原提交规则，站内筛选仍由应用按钮保存。
- `NodeLaneRow` 统一设置行、选择项与卡片按钮；`.card` 是同一实现的独立表面配置，支持懒列表首尾圆角。行高最小 56、目录卡片 72，主文字 17、辅助文字 14、右侧值 15、图标 24、箭头 20。具体设置的名称在左、当前值在右，标题下方仅放说明并占满内容宽度；长值最多两行，完整内容在原选择页或编辑框查看。分类导航不显示其中某个设置的值。`NodeLaneSliderRow` 共用同一标题／值布局，滑块数值不拼入标题；存储压缩级别也复用该组件。所有分组及卡片表面由 `NodeLaneGroupSurface` 绘制。
- 小说与播放器的普通设置选择行共用 `MobileSettingsChoice`，统一当前值、搜索选择页及取消／同值不写入行为；偏好读写仍由各页面的原 provider 负责。页面、弹层的按钮与输入主题只由 `nodeLaneModalTheme`／`NodeLaneTokens` 定义。文字按钮 15、点击区至少 44；工具栏及菜单触发器共用图标按钮几何与表面。业务组件不得另写圆角、字号或输入装饰覆盖。
- 书架、章节和迁移页面也复用这些基础组件，不维护平行实现或无调用的兼容别名。

iOS 方向依据 [Apple Materials 指南](https://developer.apple.com/design/human-interface-guidelines/materials)：浮动工具按钮、搜索与弹层使用共享 `NodeLaneGlassSurface`，内容列表保持清晰的实体分组。Flutter 层采用有界模糊、薄边和底色模拟玻璃材质，高对比度下使用实色；这不是原生 `UIGlassEffect`，不声称具备系统折射或形变效果。iOS 底部导航继续使用原生 UIKit；Android 使用同令牌的 Flutter 悬浮底栏。弹层采用较高遮盖度的常规材质，避免原生底栏与页面内容透出明显分界；没有新增网络依赖、字体或图标包。

共享组件覆盖来源目录／第三方、语言与搜索范围、仓库管理／添加／详情、站内目录／更多／筛选／选择／保存搜索、来源详情与偏好，以及开发者来源元信息和调试参数。专用代码编辑器继续使用原编辑与执行逻辑；调试参数和选择控件复用相同组件，原有平板调试区的可用范围保持不变。开销主要是可见浮动表面的模糊合成，不在每个列表卡片上增加模糊；帧率与耗电尚未测量。只调整主题颜色虽然改动更小，但无法删除重复组件及双层输入容器。

### 来源与浏览器的八个界面

按已确认的 [来源与第三方管理](design/ios-sources-and-repositories-concept.png) 和 [浏览器与网页翻译](design/ios-browser-and-translation-concept.png) 两组概念图实现；[完整提示词](design/ios-sources-browser-concepts.prompts.txt)随图保存。概念图中的网站、数量、账号与漫画内容是示例，运行界面展示真实目录和网页状态。

| 界面 | 当前实现 |
| --- | --- |
| NodeLane 来源 | 大标题、媒体菜单、NodeLane／第三方分段、搜索、常用及全部网站；点网站直接进入，所需适配器按需获取，不显示官方插件的添加／安装按钮 |
| 第三方来源 | 已安装／可安装分组，安装与更新独立点击区，保留来源设置、筛选、批量更新和自定义扩展入口；仓库管理收进弹层 |
| 仓库管理 | 真实名称及目录域名、内置官方目录标记、添加与刷新；第三方仓库详情保留显示开关、复制、网站及移除确认；仓库、添加和刷新图标统一继承行组件的中性色 |
| 添加仓库 | 网址输入与粘贴、异步识别预览、错误提示和单次确认；迟到的旧识别结果不覆盖新输入，同地址重复添加被阻止 |
| 浏览器首页 | 与空标签共用开始页：原位地址输入、新建、标签数量与常用网站；移除最近三个标签和重复提示 |
| 网页阅读 | 地址栏内直接编辑及刷新；底部后退、翻译／原译图、新建和标签，前进收进更多菜单；隐藏应用根底栏 |
| 网页翻译面板 | 范围与原译图放在一组，语言与可展开的进度摘要放在一组；失败数量默认可见，恢复动作仍由现有翻译契约决定 |
| 标签管理 | 两列网页缩略图、标题／域名、当前徽标，关闭与选中独立；底部新建按钮，达到 12 个标签时说明上限 |

底部默认入口为“书架／更新／来源／浏览器／更多”，继续使用 iOS 原生底栏。历史数据继续用于阅读进度、备份与继续阅读，没有独立历史页面入口。原导航偏好读取时剔除旧历史路由并加入浏览器，其他顺序与媒体隐藏偏好继续使用。

NodeLane 漫画目录读取内置官方地址，可用 `NODELANE_CATALOG_URL` 切换开发源。来源首页不展示目录描述、名称和服务器地址，官方条目与第三方分段隔离；不使用用户的第三方仓库代替官方目录。目录整批保存后即显示，全部兼容缺失插件及新版本在后台串行安装，不受第三方更新开关控制。点击已安装网站直接打开当前版本；点击缺失项优先执行，共用已有安装任务，只在该行等待。下拉只刷新所在分段，目录失败或手动安装失败复用 `showNodeLaneNotice` 临时浮动提示，不占列表空间、不随普通重建重复提示；自动安装失败保持安静并保留旧版本。小说、动画仍可通过第三方来源使用，尚无对应官方目录；既有第三方与已安装来源不被删除。分发、刷新间隔和验证边界见[独立插件仓库与主机契约](SOURCE_PLUGINS.md)，该入口不改变单来源漫画身份或翻译契约。

样式复用 `NodeLaneTokens`、`NodeLaneSurface`、`NodeLaneReaderSurface` 和共享图标；没有新增字体或图标依赖。根标题 34、弹层标题 22、行文字 17、辅助文字 14；边距 20、分组圆角 18、控件胶囊圆角 24、弹层圆角 24、网站图标 40、目录行最小高度 72。复用 `NodeLaneRow.card`／`NodeLaneCatalogSheet` 统一目录、仓库与网页列表；`NodeLaneCloseButton` 共用 44 点击区和 32 圆形表面。标签卡片高度 244、间距 12，浏览器工具栏高度 56。具体来源读取、账号和任务状态继续留在原服务。

浏览器首页只读取逻辑标签，不创建 WebView。沿用一个前台与一个最长 30 秒的温热 WebView，隐藏标签停止新增翻译；新建／恢复标签不自动开启任务。原图开关只改变显示，不关闭已启用的翻译。标签元数据写入串行化，关闭最后一个标签补一张本地空标签，重复关闭不会多建；预览只驻留内存，每张不超过 384 KiB、最多 12 张，关闭时释放，低清 JPEG 解码按显示尺寸限制。截图读取有超时，失败使用中性占位。新增目录读取、截图和状态存储有开销，内存、耗电与帧率未测量；纯文字标签列表更轻，但不能满足已确认的预览设计。

网站图标沿用 `NodeLaneWebsiteIcon` 和 `cachedNetworkImage` 的普通网络图片分支，按插件提供的 `iconUrl` 请求，启用既有图片库的 30 天磁盘缓存。首次加载写入应用临时缓存目录，同一 URL 可跨页面和应用重启复用；读取磁盘时检查期限，过期后按需重新下载，命中内存时直接复用，不增加后台刷新。系统清理缓存后会重新获取；空地址或失败仍显示原占位图标，不自动发现 favicon。封面与阅读图片的缓存策略保持原有配置。

### 浏览器开始页与补齐状态

按确认图稿实现：[空标签与开始页](design/ios-browser-empty-tabs-concept.png)、[阅读操作与补齐状态](design/ios-browser-secondary-states-concept.png)；[生成提示词](design/ios-browser-empty-tabs.prompts.txt)随图保留。实际实现以共用开始页和标签内原位输入为准，图稿 01 的独立空态和 03 的地址弹层不作为实现要求。图片中的网站、漫画仅为示例，实际使用现有字体、平台语义图标和 `NodeLaneTokens`，原生应用底栏保留。

| 界面／状态 | 当前实现 |
| --- | --- |
| 01 新标签 | 加号立即创建并选中空标签，直接显示浏览器开始页；默认收起键盘，不创建 WebView，不请求网页或翻译 |
| 02 开始页 | 大标题 34、地址框 48、页边距 20；新建与标签数量在右上。常用网站复用固定来源，按网站地址去重，前 4 项直接展示，最多展开至 8 项；无常用时隐藏分组 |
| 03 原位输入 | 共用 `MobileBrowserAddressField`。开始页直接填写或粘贴；网页地址点击后原位展开完整网址并选中，取消保留当前网页。非法输入就地提示，不再打开独立弹层 |
| 04 标签管理 | 两列 244 高卡片、12 间距、18 圆角；当前徽标在预览左上，关闭点击区 44。打开面板直接定位当前标签；空标签显示窗口图标、“新标签页”和“尚未打开网页”。上限 12，不静默删除旧标签 |
| 05 网页操作 | 工具栏高 56，后退、新建、标签始终直达；翻译与面板入口合并为蓝色胶囊，开启后使用原图／译图分段。前进放更多菜单，刷新只保留在地址栏 |
| 06 网页翻译 | 范围开关与原译图分组，目标语言与进度摘要分组。默认折叠逐图状态，失败／待核实数量保持可见；展开后沿用原有逐图恢复动作。未登录直达软件账号页；无图片时显示明确提示 |
| 07 加载失败 | 使用共享图标、标题 20、说明 14 和 24／16／8 间距；提供“重试”和“编辑网址”，编辑直接聚焦当前地址栏。未加载有效内容时隐藏翻译操作 |
| 08 清除登录确认 | 菜单明确清除所有网站登录状态，使用共享底部确认面板、红色文字的清除按钮及取消；确认后清理 WebView Cookie 和本地网站 Cookie，不涉及 NodeLane 软件账号 |

顶底栏使用明确的尺寸，避免 Material 默认触控留白影响对齐：内容高 56，按钮点击区 44，常规图标 24、地址与展开图标 20；返回／取消／翻译和原译图文字 17，地址文字 15。网页地址胶囊高 44，开始页输入框仍为 48。底栏两侧留白 16，翻译胶囊 132 × 44，原译图组最大宽 176；后退与中部间距 24，加号与标签间距 20，窄屏缩为 8。加载前后及原译图切换只改变中部内容，外围按钮保持原位置。标签数量使用 24 尺寸的双层窗口轮廓，与开始页共用；开始页两个右侧按钮均为 44，间距 8。

`MobileBrowserStartPage`、地址输入、标签卡片与面板只负责呈现及回调；固定来源筛选由共享 provider 读取原偏好，标签生命周期与导航仍由现有浏览器容器处理。没有新增浏览器运行时、搜索引擎、无痕、下载或收藏体系。地址仍只接受有效 HTTP(S)；空字符串仅表示设备上的逻辑空标签，`about:blank`、文件地址、脚本和嵌入凭据的地址仍不可输入。

空标签保留 ID、顺序和当前标记，网址提交及常用网站点击在当前空标签打开。最后一张关闭后只补一张空标签；恢复或再次关闭旧 ID 不多建。地址输入、刷新、新建和前进各保留一个对应入口。

最多一个前台、一个保活 30 秒的 WebView；空标签与标签预览不加载网页。网页和开始页切换时保留内容容器身份，隐藏网页不会压缩开始页宽度；隐藏期间的滚动回调和迟到的锚点不覆盖阅读位置，回到网页后恢复原位置。元数据沿用串行写入，截图缓存仍有 12 张／每张 384 KiB 上限。未测量内存、耗电或帧率；复用开始页和现有会话比新增另一套空标签导航更轻。

### 跨页组件复用

书架、来源、更多与筛选共用令牌；来源布局以上述八界面设计为准。

基础控件集中在 [`nodelane_controls.dart`](../lib/modules/widgets/nodelane_controls.dart)，图标语义集中在 [`nodelane_icons.dart`](../lib/theme/nodelane_icons.dart)。尺寸、颜色、文字角色及标准按钮主题仍由 `NodeLaneTokens`／`NodeLaneSurface` 管理。

| 界面 | 复用与保留边界 |
| --- | --- |
| 书架 | 共用大标题、圆形动作按钮、媒体菜单、搜索框与筛选按钮；搜索框只显示搜索提示，不拼接总数，数量继续由分类标签承载。封面圆角、标题、间距及未读徽章采用令牌。书籍卡片、列数计算、查询和选择仍归书架负责 |
| 来源 | 使用八界面设计中的 NodeLane／第三方分区和目录行；复用标题、媒体菜单、搜索、分段及分组令牌，来源主操作和固定、安装等按钮独立 |
| 更多 | 软件账号保持首栏，统一头像、主次按钮、分组标题和设置行；未登录、加载、失败、已登录仍由现有账号服务驱动。保留全部阅读开关及书架管理入口 |
| 书架筛选面板 | 共用面板标题／关闭、分段控件和紧凑选项行；保留六项筛选、七种排序、显示选项及来源草稿。沿用原 provider、即时保存和分区滚动位置 |

### 通知与反馈组件

参考[组件与状态](design/ios-notification-components-concept.png)、[页面落位](design/ios-notification-placement-concept.png)及[完整生图提示词](design/ios-notifications-concepts.prompts.txt)。通知由 `NodeLaneNotice` 实现，浮动入口统一为 `showNodeLaneNotice`。落位图中的背景只说明通知位置，书架卡片、浏览器操作和原生底栏继续以现有组件为准。

- 一套通知内容组件承载轻提示、结果、错误、需要处理与进度状态；通过可选说明、单个操作和进度配置变化，不按场景建立平行组件。浮动表面复用 `NodeLaneGlassSurface`，页面内提示复用分组表面，关闭和操作复用既有控件。
- 主信息使用现有 17 文字角色，辅助说明 14、操作 15；单行轻提示使用正文 16。常规图标 24、关闭图标 20、点击区至少 44；内边距 16、图文间距 12，浮层圆角 24、页内分组 18。普通图标默认 `ink`，操作和进度使用强调色，错误／破坏性动作使用错误色；不为每种状态另设整块彩色背景。
- 高度随内容增长；带说明时操作置于文字下方，长消息可换行，避免右侧按钮挤压文字。浮层位于底部导航、阅读工具栏或键盘上方并留 12 间距，不覆盖操作区；同一任务原位更新，避免叠出多条进度提示。关闭提示仅收起显示，不等于取消任务。
- 轻提示自动收起；可操作通知停留更久并可关闭，持续进度可在所属页面内显示。按钮仅绑定业务已有动作；不因统一提示而自动重试未知结果、重新创建任务或新增取消能力。
- 已移除旧 `botToast`、`ToastNotificationContent`、直接创建的 `BotToast.showNotification`／`showText` 和散落的 `SnackBar`；`toastError` 只负责记录与整理错误，呈现同样走统一入口。BotToast 仅保留已有浮层宿主、计时与路由生命周期，不再定义另一套内容样式。
- 轻提示默认 3 秒，错误 6 秒，有操作的结果 8 秒；业务可按必要性指定时长。可横滑或点击关闭，切换路由或底部标签页收起旧提示；关闭只影响显示。`NodeLaneNoticeHandle` 原位更新进度并仅关闭自身，旧任务结束不会清除新提示。异步操作防重复点击，失败记录后提示核对结果，不自动重试。
- `NodeLaneNoticeAvoidance` 测量原生底栏、阅读器与浏览器工具栏的实际位置，结合安全区和键盘高度避让；关闭工具栏时移除占位，无轮询和写死屏幕比例。更新页内展示书库进度与失败入口，移除重复错误图标、旧的第二个加载指示和完成后的强制错误弹框；任务使用既有应用级 Provider 容器，离开发起页面仍可完成。后台自动更新保持安静。
- 错误记录、备份分享、回滚、网站验证和任务进度仍由原调用方管理。确认与应用更新复用 `NodeLaneAlertDialog`／`NodeLaneDialog`；未新增系统通知、通知权限或推送能力。
- 回归覆盖替换与关闭、重复操作、异步失败、离开页面继续更新、逐项失败隔离、窄屏大字号及 RTL；iOS 模拟器已复核浅深色状态、键盘与原生底栏避让、复制提示及书库进度。Android 运行验收暂缓。

## 导航与书架

手机漫画、小说、动画共用书架页面、卡片和弹层，保留各自原有偏好与操作契约。底栏把三种媒体归入“书架”，标题下切换媒体；隐藏媒体、导航顺序与角标继续沿用原设置。iOS 底栏由 UIKit `UITabBarController` 绘制；Android 底栏由 `NodeLaneFlutterTabBar` 绘制，共用视觉令牌与玻璃表面，不维护第二套颜色或控件几何。

### Android 同风格底栏

[跨平台统一设计图](design/android-unified-glass.png)由 OpenAI 官方 API 的 `gpt-image-2.6-sunburst` 基于现有 iOS 设计编辑生成，[提示词](design/android-unified-glass.prompts.txt)保留参考与尺寸。图中封面、网站及账号都是示例，实际页面保留已有数据、配置和功能。

- Flutter 底栏左右留白 16，胶囊高至少 64、圆角 32、内边距 6，上下留白 8，底部再避让系统手势区。图标 24、标签 12／1.3 行高、间隔 4；大字号增加底栏高度。选中背景包住图标与标签，未选中图标使用正文色，角标沿用强调色并保留真实数量的读屏信息。
- 只在整个底栏外壳使用一层 `NodeLaneGlassSurface`，周围没有矩形底板或顶部分割线；高对比度改用实色但保留几何，减少动态效果时关闭选中态过渡。切页、媒体记忆、隐藏入口、超过五项的更多面板、角标和详情返回时的书架滚动保持原契约。
- 共享令牌不再按操作系统选择圆角、填色或图标。`NodeLaneSwitch` 统一行内与独立开关；`NodeLaneSliderRow` 与阅读器复用同一轨道／滑块主题，继续点按或拖动调整、松手提交。平台适配仅用于系统能力与 iOS 原生底栏，不把整个 Android 主题伪装为 iOS。
- 浏览器地址栏复用相同输入表面，开始页高至少 48、页面内紧凑地址栏 44；标签数量按钮复用浮动工具表面，保留原位编辑、粘贴、校验、刷新和取消。
- 字号、字重、间距与颜色共用令牌，继续尊重用户字体及系统字形回退。玻璃是 Flutter 有界模糊，不包含 UIKit 原生折射；不增加字体包、网络调用、后台任务或封面模糊，帧率和耗电尚未专项测量。

### 高频操作与折叠

- 常显标题、媒体菜单、搜索、筛选、直接导入的加号，不增加搜索提交按钮。更多提供更新／停止、选择作品、随机打开、分类管理；动画保留种子入口。“搜索时忽略筛选”在更多内展开，导入不再重复出现。
- 书架续读与详情阅读入口共用章节跳转规则。已读完的作品仍显示阅读入口，从阅读顺序中的第一章第一页重新打开；未读完的作品保留原续读页码，明确点选某一章仍打开该章。章节匹配改用 ID，移除整段 JSON 比较和找不到下一未读章就静默退出的分支。
- 长按或“选择作品”进入多选。卡片隐藏徽章与续读，显示选择圈；顶部取消、数量、全选，底部只显示分类、已读／已看、更多。未读／未看、反选、迁移、移除收在更多。全选／反选针对当前分类中经过搜索和筛选的可见结果；进入空选择时写入操作禁用。分类数量与全选范围使用同一份筛选快照，移除重复查询和默认分类的独立计数逻辑。
- 筛选、排序、显示仍为三个分区，即时保存，各自保留滚动位置。六项筛选直接选择不限／包含／排除；七种排序与升降序分开，重复点当前项不反转。四种布局使用视觉选项卡，常显续读开关；下载、语言、来源、本地、分类标签与项目数收在当前弹层的“更多显示选项”。
- 来源筛选保留独立可搜索草稿：搜索不丢弃隐藏选择，取消不写入，重置只改草稿，应用前过滤失效来源。来源徽章仍沿用全局偏好，其他媒体显示项按原字段隔离。显示、排序、来源及三态筛选改为通过现有仓库在事务中读取最新值，只写当前字段，避免弹层保留的旧快照覆盖前一次操作。
- 空书架优先浏览来源，并携带当前漫画／小说／动画类型，其次本地导入；有关键词但无匹配优先清空关键词，其次调整筛选。分类或条件无结果不误报为空库。

### 导入、分类与移除边界

- 本地导入单一卡片直达系统文件选择器：漫画 ZIP／CBZ，小说 EPUB 与拆章开关，动画保留原视频格式。选择取消可重新选择，处理中禁止返回和重复导入。失败提示核对可能已加入的内容，不能从同一弹层再次执行。种子地址／文件沿用原 provider，失败同样不自动重试。
- 分类按媒体读取，名单按需构建，管理、取消、保存固定可达。批量初选取全部对象的分类并集，勾选可见分类统一替换；已收藏单本保留隐藏分类，新收藏可选择隐藏分类。保存前重新读取当前记录，复制后仅修改分类及原收藏字段，过滤已经删除的分类；成功才退出选择，失败只关闭并核对。
- 移除打开时固定当前对象范围，数量与完整名称可展开查看。书架记录和下载文件独立选择，默认均不选；取消保留选择，处理中禁止返回／重复提交，失败只能关闭。原文件删除、章节记录处理与本地包规则保留，不增加任务、回滚或重试层。
- iOS 本地包旧沙盒绝对路径失效时，仍只核对当前沙盒 Documents／Library／tmp 下相同相对路径，存在才读取；不移动文件、不按名称搜索其他目录。

手机入口复用共享控件，桌面／电视保留各自仍在使用的组件。查询、排序、阅读进度、导入、分类保存和删除继续由原 provider／仓库承担。新增开销是可见卡片、当前弹层和局部草稿；不增加逐本历史订阅、网络调用或后台任务，封面不加模糊层。未测量内存或帧率。仅改颜色更轻，但不能解决选择栏拥挤、层次不一致和低频设置常驻，因此替换视图与共享控件。

原生参考：[Apple Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)、[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[UITabBarController](https://developer.apple.com/documentation/uikit/uitabbarcontroller)。

### 现有实现

- 来源输入框按网站名筛选目录，“搜作品”保留在右侧菜单；有关键词但未匹配网站时，空态显示共享令牌样式的“跨来源搜索”按钮。菜单、空态按钮和键盘搜索共用带词跳转；无关键词且目录为空时才显示添加仓库入口。
- 目录语言筛选只影响当前分区展示，搜索范围只包含已安装且允许显示的来源；无来源时进入当前媒体第三方分区。首次目录展示沿用已有活动语言，修改本地语言选择不改变来源记录。
- 扩展详情按“名称／版本／语言 → 来源设置 → 高级操作”排列。设置写入、编辑代码、Cookie 清理和卸载调用原流程；卸载保留确认，开发工具仅在开发者模式下显示。
- 手机仓库添加、识别和移除使用新仓库弹层；桌面及电视保留对话框。弹窗控制器在退场动画结束后释放，异步结果只更新仍挂载的页面。
- 批量迁移来源入口同样使用 `NodeLaneRow.card`；来源和目录不再各维护一套卡片行。独立操作通过分组或行尾插槽组合，不触发行的导航回调。
- 独立历史页及其导航双击处理、页面媒体状态已移除；历史存储、阅读进度、备份、统计和电视继续阅读仍使用原模型与服务。

## 全局搜索

- 手机使用常显搜索框，通过键盘“搜索”提交，不设外部搜索按钮，搜索范围入口放在输入下方，不重复显示已提交关键词标题；编辑草稿不联网，不清空当前结果。入口携带的关键词去除首尾空格后直接搜索，空词只显示输入提示，不再读取来源热门列表。键盘与短屏下搜索区可滚动，结果独立滚动；桌面与电视保持原布局。
- 来源标题与语言完整换行，结果仍按来源分组横向浏览。每行高度随封面宽度和文字缩放计算，标题保留两行及完整辅助功能名称。手机使用轻量书库角标，不再把整张封面变暗；空封面直接显示本地占位，图片加载或请求头解析失败不阻挡标题和操作。打开详情、长按快速收藏和原收藏匹配规则保持不变，不合并来源身份。
- 手机空结果与失败分别保留紧凑来源卡片，失败可独立重试或打开网站；桌面仍集中折叠。无可用来源时区分未安装、仅置顶和内容过滤，分别提供第三方目录、搜索范围或浏览设置入口。当前搜索的勾选集保留在页面内，原“仅常用”偏好按原方式保存，不新增持久化范围配置。
- 请求由现有 `searchProvider` 执行，页面管理订阅，展示组件只接收数据与回调。查看全部使用结果所属的关键词并复用首屏；查询变更或离页释放分组订阅，旧空结果回报按轮次丢弃。
- `FetchGate` 由独立工具文件维护，最多同时执行 3 个来源请求；排队项获得并发位后检查挂载状态，已离页的不再请求，已启动请求仍由原服务负责。每个当前来源分组多保留一个订阅，没有新增永久缓存或轮询；实际内存与性能尚未测量。

- 手机使用常显搜索及键盘提交，支持最新的来源显示热门／最新切换；搜索或筛选时显示对应结果标题，并用一个“返回热门”操作退出查询。编辑搜索草稿保留当前结果。有效网站地址直接从页头打开浏览器；“更多”集中显示方式、保存搜索、已保存搜索、筛选和来源设置。仅有已提交关键词时显示保存操作，仅插件声明了筛选项时显示筛选入口；网站说明默认折叠在弹层中。移除搜索框内重复的已保存入口、结果区重复标题和主页面的筛选按钮，沿用原请求、路由与按来源保存的关键词。
- 站内搜索由已提交关键词或已应用筛选决定；首屏、分页和重试共用同一参数入口，纯关键词查询与跨来源搜索参数一致。桌面搜索框是否展开只控制显示，不决定请求类型。
- 舒适网格使用下方标题，紧凑网格只显示封面并保留辅助功能名称，列表保留封面与名称。列数沿用原媒体密度设置并限制手机最小卡片宽度；结果按需构建，关闭卡片自动保活，分页状态占完整一行。已有书库记录仍通过原单个来源订阅匹配；点按详情、长按收藏及来源身份规则不变。
- 手机空封面不请求远程白图，图片或请求头失败显示本地占位，自定义封面按显示尺寸解码；旧列表的图片失败也限制在固定封面尺寸内。沿用现有网络缩略图缓存，不引入独立图片缓存或站点处理。
- 热门／最新首次访问才请求；切换保留各自的分页、在途读取和滚动位置，清空搜索返回已加载的热门列表。手机下拉刷新当前列表，空列表和短列表也可触发；失败保留已有内容。新关键词或筛选替换唯一搜索结果集，按轮次拒绝迟到分页；两种浏览列表的迟到结果只更新各自状态。失败使用共享浮动提示和重试动作，不在内容区保留错误卡片。空末页更新结束状态，本地来源仍按 50 条页长判断尾页；全量来源每次只增加最多 50 项展示，不请求下一页。
- 初始化时只读取一份默认筛选，当前条件与编辑草稿分别深拷贝；返回取消不改已应用条件，确认与显式重置沿用来源原类型和默认值。长选项使用共享选择弹层，键盘避让与文字控制器生命周期由视图处理；没有新增筛选存储层。切换热门／最新恢复默认条件，避免后续关键词查询暗中带入旧筛选。
- 筛选字段与选项来自插件的 `getFilterList` 或对应适配器元数据，并非根据网页生成。手机筛选编辑器复用共享令牌、分组行、选择弹层及底部重置／应用操作；常见字段、状态、排序和题材名称在显示时按完整标签匹配 App 语言包。新增词条提供中英文，其他语言沿用已有翻译或英文回退；未知名称和网站说明保留原文，不接入文本翻译服务。原始名称、类型、选项值与用户输入不做转换，切换语言不会重置草稿。筛选深拷贝放在模型层，视图只回传选择，服务层不依赖本地化或手机组件。
- 页面最多保留两份已访问浏览列表的元数据、两个首屏订阅及一份可替换的搜索结果和筛选草稿，退出后释放；隐藏列表不主动翻页，不预加载未访问列表，不增加磁盘缓存或后台轮询。内存与帧率尚未测量。切换时清空数据更省内存，但会重复请求并丢失位置；实际封面仍由原懒列表与图片缓存管理。

## 迁移搜索与确认

- 手机迁移和从追踪条目添加共用常显搜索，保留原媒体、置顶来源和关键词规则。预填词只初始化一次，清空后显示搜索提示；编辑草稿保留已提交结果，新词直接切换，不再发送中间查询。无来源时引导至对应媒体的扩展分区或原浏览设置。
- 来源按需构建、横向浏览，沿用全局搜索的展示卡片和三路并发门控；每个搜索页面持有自己的队列。失败来源可独立重试，空返回显示无结果；已释放的排队行不启动请求，已启动的请求仍由原 provider 处理。空封面使用本地占位，移动端卡片不长期保活，来源身份匹配和订阅仍留在原调用方。
- 点选候选后先打开全屏预览，显示当前作品、目标来源和可折叠章节。读取失败可明确重试，取消后的迟到结果不再更新页面；底部固定确认和取消。追踪添加把分类选择放在同页，沿用原分类订阅、编辑路由和分类 ID，提交时过滤已不存在的选择。
- 确认继续调用原迁移服务或原书库／追踪写入顺序，视图只管理读取、选择和操作状态。提交期间禁止重复触发和返回；失败直接显示可能部分完成的说明及完整原因，不提供再次写入按钮。用户可关闭并核对书架，页面不自动重建或重试写入。
- 只提取复用的搜索输入与并发门控，不增加迁移协调层、缓存或来源协议。主要新增开销为可见结果、一次详情预览和当前分类订阅；内存与帧率尚未测量。保留原弹窗改色更轻，但无法清楚容纳目标摘要、长章节和固定操作，因此手机采用独立页面，桌面／电视保留原主布局。

## 批量迁移

- 手机保留“原来源 → 选择作品 → 目标来源 → 匹配复核与执行”四步。来源卡片显示语言和作品数量，沿用原分组、媒体、内容过滤和目标来源排除规则；选书默认全选，点按、全选／取消全选及长按范围选择继续由原页面负责，下一步只传递选中的原对象。
- 复核卡片把原作和目标上下排列，完整展示名称、数量、搜索词与失败原因；跳过、迁移和更换候选独立操作。章节仍只预览前 12 条并显示其余数量，展开状态按作品和原／目标章节分别保存；不为预览复制整份章节名称列表。
- 更换候选复用现有可搜索选择页，取消或选择已就绪的当前项不重新读取。选择和详情读取期间禁用开始迁移，同一条目的选择也暂时禁用；详情失败后可明确重新选择并重读；只有一个候选时直接提供重试，失败项不进入迁移。旧回调、重复开始及离页后的结果均有状态检查。
- 匹配继续逐本执行并保留原两秒间隔，进度按已返回的结果计算；执行继续调用原迁移服务，处理中禁止普通返回。完成页保留迁移、跳过和失败计数及失败作品，可能部分写入时提示先核对书架，不增加自动重试；全部跳过时明确显示未选择迁移项。没有新增后台任务、事务或进度恢复算法。
- 手机卡片按需构建，封面按小尺寸展示，自定义图片按显示宽度解码，网络图片复用缩略图 provider；空封面和请求头失败使用本地占位。仅共享现有展示组件，不引入新的迁移状态框架；资源开销尚未实测。沿用旧横向双封面会更轻，但会挤压手机书名和操作，因此仅手机改用纵向摘要，桌面／电视保留原主布局。

## 更新与阅读记录

阅读记录用于书架恢复与统计，没有独立页面入口。

- 更新使用大标题、媒体菜单和常显搜索，保留各媒体的数量角标、刷新／停止和错误入口；删除全部仍需原确认。媒体隐藏偏好即时同步，按媒体身份保留选中项，只有实际切换媒体才清空查询；没有可见媒体时隐藏维护操作。
- 记录仍按原日期规则分组。手机行改为可伸展卡片：封面进入详情，文字区域调用既有继续阅读入口，删除或下载保留独立点击区；已读标记、下载状态与章节查询不在卡片中计算。
- 查询无匹配时显示“无结果”与重置入口，无记录时显示原业务空态。键盘显示时收起标题和媒体栏，收起后恢复；列表末尾为平台底栏留白，按媒体保存滚动位置。
- 书架和详情复用阅读入口解析：未读进度继续恢复，全部已读时仍可从首章首屏重新阅读，不清空已读标记或保存的页码。

## 更新错误与错误报告

- 长按后的 Android 系统返回先取消选择；底部操作避开系统安全区。没有后续章节时不展示“标记后续已读”操作，避免原入口越界；删除确认允许滚动和按钮换行。本地信息编辑弹窗在键盘上方可滚动，取消不写入，控制器在退场后释放。
- 手机漫画详情使用下述目录设置；其他媒体继续使用原筛选、排序和显示弹层，桌面与电视布局保留。

### 详情与章节加载

[加载状态设计稿](design/ios-manga-loading-concept.png)与[生成提示词](design/ios-manga-loading-concept.prompts.txt)覆盖首次详情、目录等待、打开章节和失败重试。插画和书籍为示例；实现按当前共享令牌取值，详情标题 26、章节标题 18、元信息 15，阅读过渡页书名 20、章节名 15、封面 96 × 136，沿用既有圆角、间距和主题色。

- 详情用已有 `MobileDetailOverview`／`MobileDetailHeading`／`MobileDetailPrimaryActions` 保持内容几何。仅本地记录尚未到达时展示整页骨架；已有封面、书名、来源、简介和章节在刷新时保留，只替换缺失区域。目录加载时不显示“0 章节”或“无结果”，没有章节的阅读入口暂不可用，书架操作保留。已移除顶部悬浮的小加载圈；首次加载、下拉刷新和菜单刷新共用更新方法，两个刷新入口共享加载状态与重复调用保护。
- `NodeLaneSkeleton` 是唯一骨架绘制控件，封面网格也复用它。占位复用 `NodeLaneGroupSurface`，不为每条骨架创建动画控制器；目录只构建三条占位，真实章节仍按需构建。网格原有单一动画及减少动态效果行为不变。
- 手机阅读入口用 `MobileReaderEntryState` 替换旧的空白加载／错误页面。顶部可返回，中间保留封面、书名与章节；`NodeLaneNotice` 显示获取图片或失败提示，重试复用原章节缓存清理和请求失效逻辑，连续点击只执行一次。状态变化不移动封面与书名，大字号内容可滚动；请求完成沿用原入口进入阅读。桌面与电视保留既有布局。
- 章节上下文由共享 `readerChapterProvider` 提前提供，页面与读取图片的 provider 共用同一次本地查询，页面获取失败不会抹去上下文。封面复用既有图片提供器和缓存，无新增轮询、模拟百分比或后台任务；离页释放 provider 订阅，异步回调不再更新已退出的界面。实际真机性能尚未测量。

回归覆盖目录等待、已知信息保留、大字号与返回、失败后重试、重复点击和离页后完成；iOS 模拟器以独立预览复核布局，不代替真实来源服务的端到端验收。Android 调试 APK 已通过编译、模拟器覆盖安装及启动，真实来源加载交互与真机验收仍待完成。

### 漫画详情操作与下载范围

- 手机漫画详情的更多操作改为底部弹层，固定标题和关闭，完整书名及操作列表独立滚动。刷新／分类／分享、迁移／批量迁移／扩展设置、元数据导出分组展示；仍向原分发器传递相同操作编号。已收藏漫画即使没有分类也能进入分类选择及管理，其他平台和媒体保留原菜单。
- 下载范围使用相同的视图容器，明确按当前目录筛选选择并跳过已下载章节，保留下一章、下 5／10／25 章、未读及所有章节。目录无条目时显示说明并禁用选项；实际选择、顺序、队列排除和入队仍调用原方法，没有按视图重新实现下载规则。
- 弹层从根导航打开；关闭、普通返回和遮罩退出不执行操作，选择只回传一次结果。回调未完成期间禁用对应入口并显示进度；异常只提示先核对状态，不泄露底层异常或自动重复调用，离页后不更新显示。仅增加两个入口各自的临时状态及最多七个菜单行，无新查询、订阅或业务状态层。仅改变旧弹出菜单尺寸更轻，但不能同时清楚展示操作对象、分组和下载范围说明；真机开销未测量。

### 漫画目录筛选与排序

- 手机漫画目录设置从根导航打开，保留固定标题、分区和关闭入口，短内容随内容收缩，长内容限制在屏幕高度的 75% 内并独立滚动。下载／未读／书签直接选择“不限／包含／排除”，沿用原三态字段；名称在分配宽度内不能单行显示时，共享选择控件改为名称在上、选项在下，避免拆开单词；本地漫画仍隐藏下载条件。条件即时生效，切换分区保留各自位置。
- 排序条件与升／降序分开，选择当前项不再反转方向；回调读取当前 provider，拒绝旧回调重复反转。保留翻译组、章节编号、上传日期及名称的原排序规则，当前按翻译组排序时即使已无组名仍显示该条件。原比较器的 `reverse=true` 对应升序，视图按该语义标注。
- 翻译组使用独立可搜索草稿，明确勾选表示隐藏；搜索保留不可见的选择，重置只影响草稿，取消与返回均不写入。确认时通过原章节仓库的索引查询重新核对一次可用组名，过滤已消失的项，避免读取被覆盖页面暂停的流快照；不新增来源身份或过滤规则。
- 原“显示”页没有接入保存或章节渲染回调，手机漫画不再展示这两个不生效的选项，现有章节名称显示保持不变。没有为此新增偏好字段。
- 原章节偏好 provider 改为在既有写入队列中合并当前漫画的记录，避免连续操作覆盖其他字段或其他漫画；翻译组首次保存不再立即强读尚未写入的记录。仍使用原设置仓库、字段和查询算法。新增开销是草稿、搜索控制器和确认时的一次章节读取，退出后释放；未测量真机资源开销。仅给旧三态框增加提示更轻，但不能明确选择排除条件或解决排序方向混用与草稿取消问题。

### 漫画章节批量操作与删除确认

- 手机漫画选择栏显示所选章节数及全选／反选文字，底部操作复用 `NodeLaneToolbarAction` 和玻璃表面，使用平台语义图标并避开系统安全区。单章书签按当前状态显示添加或取消，多章仍逐章切换书签；已读操作沿用原统一目标状态。仅单选且当前目录下方还有章节时显示“下方已读”，范围继续取当前排序和筛选后的目录。
- 下载与删除沿用原条件：非本地且所选章均未下载时可下载，包含下载章或本地章节时可删除；混合选择的下载删除仅列出有下载的章节。新视图不查询下载服务或持有另一份选择状态，入口沿用既有 provider 与仓库。
- 删除确认显示完整书名、作用范围和可展开的章节名单；长名单有界并按需构建，确认／取消固定在弹框操作区。本地移除章节记录和阅读进度，保留原始压缩包，已有下载副本继续交给原清理方法；在线仅清理下载并保留章节信息。本地全选时提示漫画也会从书架移除。
- 手机批量入口在操作完成后才退出选择，处理中锁定选择和普通返回、拒绝重复触发；取消保留选择。失败说明可能已部分写入，不自动重复调用，删除弹框失败后只能关闭。书签、阅读状态、追踪和下载入队复用原实现；没有新增回滚、后台任务或下载清理协议，原文件清理方法对部分文件异常的处理保持不变。
- 本地章节移除后，在既有写入队列的事务内重新核对剩余目录，只有确实为空才移除漫画，并等待完成后离开详情；避免原来按旧数量判断和延迟删除伤及确认期间新增的章节。弹框保存原路由引用，详情因记录删除而先被订阅销毁时仍能清除选择并返回。新增开销为本次选择快照、弹框名单、本地确认时的一次索引读取及移除后的计数核对，退出后释放；真机开销尚未测量。仅给旧图标增加提示更轻，但不能展示删除范围或处理重复确认与写入中离页。

- 目录使用有界底部弹层，章节排序、筛选与切章沿用原流程。手机漫画采用下述可搜索目录；小说及动画继续使用原入口。
- 手机详细设置按阅读模式、通用、图像滤镜分区，作用范围及暂停规则见下文。分段与关闭固定；选项名称与当前值同排，颜色增强滑杆单独占一行。桌面和电视保留原阅读模式、通用和自定义筛选三页。
- 阅读器与网页共享翻译面板和原控制器。手机明确分开“翻译当前阅读范围”与“原图／译图显示”；显示切换不自行启用翻译。未登录保留设置入口，未开始且没有信息的状态行隐藏，已有逐页恢复操作继续显示。不增加来源／服务分支，不改任务身份、渠道、费用或恢复协议。

### 漫画显示快捷面板

- 手机漫画的显示菜单改为有界底部面板，固定标题与关闭，书名、阅读模式、单双页和裁边独立排布。保留七种原阅读模式及选择一项后返回阅读的交互，当前模式不能重复应用；横向连续模式明确只显示单页，双页偏好保留但入口禁用。
- 阅读模式与手动单双页标明用于当前漫画，裁边标明用于所有漫画；自动双页开启时，说明手动切换会关闭全局自动双页。单双页现值仍向原阅读器读取，旋转时不在视图复制判断算法；回传前再次核对当前模式与值，旧回调不能重复切换或越过横向连续限制，已离开的阅读器不应用迟到选择。
- 原阅读模式与单双页保存改为在既有设置写入队列中合并当前漫画记录。写入保留裁边、自动双页及其他漫画的最新偏好；模式转换、页码换算、自动滚动和图片处理继续调用原入口。新增开销为一个面板、七个选项及既有偏好订阅，关闭后释放，不新增图片解码或持久层；真机开销未测量。给原弹出菜单加分隔线更轻，但无法同时容纳完整作用范围和横屏下固定关闭入口。

### 漫画阅读目录

- 手机漫画目录固定章节数、搜索、定位当前章节及关闭入口；正文显示完整书名、原筛选／排序范围、章节全名和正在阅读／已读／未读状态。书签按钮独立显示添加或取消；空目录和当前章被原筛选排除分别提示。
- 打开时取得原 `getSortedFilteredChapters` 的一次快照，输入仅在该快照内按章节名或翻译组匹配，不改原筛选和排序、不请求来源。定位清空搜索并收起键盘，复用已有列表控制器按章节 ID 对应的索引定位，替代估算像素偏移；长目录按需构建，不新增封面加载。
- 当前章节只关闭目录，其他章节先回传给仍有效的阅读器，再使用原路由替换入口。重复选择、已离开的入口和阅读器已切换章节时的迟到选择不再导航；切换前重新核对目标记录及所属漫画。书签通过原写入队列的事务更新最新记录的书签及更新时间，不覆盖最新阅读进度，也不重建已删除记录；关闭目录时重新读取当前章的书签图标。
- 书签写入完成前禁用选择、重复写入和普通返回，面板不以拖拽手势关闭；失败保留原显示并提示关闭后核对，不自动重试。搜索控制器、偏好覆盖和列表控制器随面板销毁释放。新增开销为本次目录快照的搜索结果、少量书签显示值和操作时的记录读取，未引入新的服务或持久层；真机开销未测量。只改原列表外观更轻，但不能解决同名章节定位、短屏搜索和弹层销毁后导航的问题。

### 漫画图片操作

- 手机漫画长按图片立即打开有界底部菜单，固定标题和关闭入口，完整书名、图片所属章节及从 1 开始的页码随内容滚动。保存、分享、设为封面分别显示用途；明确作用于原始整页，不包含翻译、分割裁剪或阅读滤镜。相邻预加载章节使用图片自身的章节信息，过渡页不打开菜单。
- 图片字节复用原压缩包、本地文件或缓存读取；加载失败可以明确重试，同次只读一次，关闭后忽略迟到结果。菜单不解码预览、不新增下载或翻译请求；保存沿用原文件名规则、扩展名识别与存储路径，iOS 明确为当前应用存储位置的 Pictures 文件夹，Android 为 Pictures/nodelane-comics。
- 保存成功显示“图片已保存”并禁用本次重复保存；分享调用原系统入口，返回后不将取消当成成功发送。任一操作等待时阻止重复触发和普通返回，菜单不以拖拽关闭；异常提示关闭后核对，不在结果未知时自动重复执行。路由已离开时不更新界面或误退下一页。
- 设为封面沿用小于 5 MB 的限制，超限仅禁用封面操作；确认在同一面板内显示完整对象，取消回到操作列表，不重读图片。确认通过既有漫画仓库写入队列更新最新记录的封面与更新时间，保留期间改变的其他字段；记录已删除则报错，不重新创建。调整仅限手机漫画阅读器，其他媒体和平台继续使用原共享入口。
- 新增开销为一个菜单、三个操作及当前图片字节引用；文件读取与写入、系统分享沿用原能力，关闭后释放菜单状态，不新增持久层或图片副本预览。真机内存及耗时未测量。仅给旧图标补文字更轻，但无法同时交代原图范围、保存去向和封面确认，也不能处理等待期间的重复操作。

### 漫画详细阅读设置

二级单选页已按 [阅读选项设计稿](design/ios-manga-reader-pickers-concept.png)及 [生成提示词](design/ios-manga-reader-pickers-concept.prompts.txt)接入共享 `MobileReaderPicker`。阅读模式、缩放类型、背景颜色与导航布局仍分别提供原有的 7／4／4／6 项；点击反转、隐藏阈值、缩放起点、动画速度、闪屏颜色、章节滑动动作和滤镜混合模式复用同一组件。标题 22、选项 17、说明 14；外边距 20、分组圆角 18、面板圆角 24，普通／缩放／色块行高分别为 56／88／80。图标走 `NodeLaneIcons` 的 iOS Cupertino 映射，缩放示意为 42×48 的静态绘制、色块 40、选中勾 24，颜色和文字继续尊重现有主题与字体偏好。

阅读器内的选择留在同一底部面板，以内部路由保留原分区、展开状态和滚动位置；左箭头返回上一层，右上角关闭整个设置，取消均不写入。点选原有值只返回，改变选项才调用原偏好入口，选择期间自动滚动继续暂停。全局阅读设置复用同一选择视图，默认阅读模式保留“仅未单独设置的漫画”作用范围。现值滚动到可见位置，长列表及横屏可以继续滚动；缩放说明垂直居中；作用范围与选择提示统一在标题下方，沿用翻译语言抽屉的 20 点对齐。选择页共用 `NodeLaneCatalogSheet` 的内容高度模式，短列表随内容收缩、长列表限制最大高度并滚动，取消原固定比例和底部撑空布局。阅读器内部导航按面板实际高度调整，返回恢复设置高度、分区和位置。新增开销仅为有界选项视图和一个内部导航器，关闭后释放，无图片解码、网络或新缓存；开销尚未做真机测量。沿用全屏选择路由的实现更轻，但无法保留设计要求的阅读背景和同一面板返回层级。

页码由 `PageIndicator` 展示。通用设置与选择页复用背景色块，自动背景的半明半暗标记保持一致；展开组与滑杆标题使用现有文字令牌。桌面／电视阅读设置、图片菜单及小说入口继续使用各自的组件。

- 阅读模式页先显示完整书名和单本说明，再提供当前漫画模式；连续模式下显示自动滚动及原 2–30 速度范围。全局部分明确用于所有漫画并即时保存，裁边常显，页面布局与连续阅读选项按需展开；不适用于连续模式的横屏缩放和放大后导航继续隐藏，隐藏不清除原值。
- 通用页保留原缩放、背景、页码、屏幕常亮和翻页动画；导航与闪屏选项收进独立展开组。布局、连续阅读、导航、闪屏、选择行和滑杆从全局设置页面提取为共享视图，继续使用同一批 provider；阅读器不额外展示目录滑动动作。边距、闪屏和自动滚动速度只在松手时保存，选择页取消不写入。
- 图像滤镜明确只影响阅读画面，不修改原图。反色、灰度、亮度／对比度／饱和度及各自重置、RGBA 与混合模式全部沿用原字段、范围、预览和保存时机；自定义滤镜关闭时保留通道值。RGBA 回调读取其他通道的最新值，避免连续调整覆盖另一个通道。
- 打开设置暂停自动滚动，进入选择页或改变模式期间继续保持暂停；关闭时仅在阅读器仍存在、当前为连续模式、开关开启且需要恢复时继续。重复选择与关闭只返回一次，阅读器离开后不应用迟到选择或恢复滚动。自动滚动保存改为在原写入队列内合并当前漫画记录，保留其他漫画和全局偏好；没有新增定时器或存储层。
- 新增开销为当前弹层、分区滚动位置和滑杆草稿；展开组复用已有偏好订阅，不增加图片解码、网络或缓存。真机开销未测量。仅重排原长列表更轻，但会继续混淆单本与全局作用范围，也无法处理设置未关闭时提前启动滚动的问题。

## 小说阅读内控件与听书

- 手机底部提供章节进度、上一章／下一章，以及目录、字号、听书、设置四个具名入口。控件叠放在阅读页上，大字号时操作换为两列；复用有界、可滚动的阅读面板，隐藏时不接收点击或语义焦点。共享面板裁切滑出动画，避免隐藏页头画进顶部安全区。
- 连续模式从已布局的滚动控制器读取可用范围，首次打开长章节即可拖动；百分比舍入、分页／双页标签和跳转仍使用原规则与回调。目录、阅读记录、章节解析和分页算法保持原入口。
- 字号从工具栏按钮浮出 8–40 的共享滚轮，停止滚动后才写原偏好；再次点击字号或外部关闭，阅读区域和工具栏高度保持不变。阅读设置复用全局小说设置页面，仅当前书籍入口插入阅读模式、单／双页、自动方向和自动滚动控件；取消选择不写入，隐藏选项保留原值，使用原单本控制器及暂停／恢复规则。
- 听书与阅读操作共用底部面板，播放器位置和身份保持稳定，收起／展开工具栏不重新创建播放器。段落进度、播放／暂停与前后段边界取自原语音服务；停止操作不因等待或失败禁用，操作等待中防止重复提交，收到原状态或段落事件即可恢复操作。初始化失败显示通用反馈，关闭后到达的初始化结果不再开始朗读，关闭回调只执行一次。
- 桌面和电视保留原布局；小说服务、语音单例、原有流订阅和平台协议不新增分支或实现。

## 多标签浏览器

- 浏览器为独立根入口，来源长按菜单也可直接打开网站，无需先安装来源。网址弹窗与浏览器内共用输入视图，沿用 HTTP／HTTPS、长度和嵌入凭据校验，非法输入留在弹窗内提示；取消不导航，控制器随弹窗释放。
- 上方显示返回应用、页面标题／主机名与菜单，点击地址区域编辑完整网址。下方固定后退、前进、翻译或原译图、面板展开和标签，禁用状态取自原历史记录；刷新、新标签与网站登录状态清理仍调用原流程。
- 标签收进按需打开的两列缩略图弹层，显示标题、主机名和当前选中状态；选择与关闭为独立点击区。新标签操作固定在安全区内，达到原有 12 页上限时禁用并解释原因。短屏、大字号时限制工具栏高度，标签列表与输入弹窗可滚动。
- 原 WebView 保活、历史、锚点、翻译控制器和释放规则继续负责行为。视图只显示加载进度和主框架连接失败状态，失败保留手动重试；不把子资源失败当整页失败，不记录原始错误或签名网址。
- iOS 的新窗口链接在导航回调中转交原标签创建入口并取消原页跳转。当前 WebView 依赖对未接管的新窗口会回退到原页加载；在创建原生新窗口前处理可避免重复导航，也无需额外保活控制器。Android 保留原新窗口入口。

## 更多与设置入口

首次启动且尚未手动选择显示语言时，按系统语言偏好匹配现有翻译，优先精确地区、再匹配同一语言，均不支持时使用英语。复用 Flutter 的语言匹配，不写入强制默认语言；之后启动仍读取系统偏好，已保存的手动选择保持优先，不改动现有设置。

- 手机更多与设置首页合并。顶部账号摘要与搜索，以下依次为常用、阅读与翻译、应用偏好、数据与管理；分类／统计／日历收进“更多工具”，关于与帮助保留独立入口。子页继续原路由、底栏继续原生实现；隐藏浏览器底栏后，更多仍提供浏览器入口。

- 选择页、文本弹窗和追踪预览仍由原调用方负责路由、验证与设置写入。特殊缩放预览通过 `NodeLaneRow` 的尺寸插槽实现；基础列表、开关、按钮、分隔线不复制。该视图不增加网络请求、存储模型或后台任务；吸顶与展开只增加在屏控件的布局和短时动画，性能未做专项测量。

| MyAnimeList | 各平台均为 `nodelane-comics://myanimelist-auth` | iOS、Android、Other 三个自有 Client ID 已接入，三个应用都须登记此地址；真实账号登录待设备验收 |
| 自建同步服务 | 移动端 `nodelane-comics://oauth-callback`；桌面 `http://localhost:48765/callback` | 由所选服务的部署者允许相应回调；真实登录与同步待验收 |

AniList 各平台共用新回调，按官方 [Implicit Grant](https://docs.anilist.co/guide/auth/implicit) 接收 URI 片段中的令牌。授权请求只传 `client_id`、`response_type=token` 与独立 state，回调采用 AniList 应用后台登记的 `nodelane-comics://anilist-auth`，不在请求中覆盖 `redirect_uri`，也不内置 Client Secret；旧应用 ID、密钥、换码请求及本地 HTTP 回调已移除。收到结果后校验完整回调地址、唯一参数与有效期，再读取 Viewer，成功后保存绑定 `55972` 的凭据；旧凭据不复用，需要重新登录。并发登录合并，取消或失败可重试，释放后忽略迟到结果。Windows／Linux 通过外部浏览器及已有应用协议接收回调，临时链接订阅在完成、失败、释放或十分钟超时后取消；手机与 macOS 沿用系统授权会话。复用现有账号存储与登录组件，不增加后端或授权框架；开销为一次 Viewer 查询及桌面登录期间的订阅，性能未专项测量。

MyAnimeList 的 iOS Client ID 为 `79c9fc22f3d141372e12b62e48ffddfd`，Android 为 `8205c12a0bef7f51110aa5ba5bcc8533`，macOS／Windows／Linux 共用 Other 类型的 `d3e6963529b9fe709b42e6dc3eb24856`。按官方 [OAuth 说明](https://myanimelist.net/apiconfig/references/authorization) 使用 PKCE plain，每次生成独立 verifier 与 state；授权和换码均传入上述固定回调，校验地址、state 和唯一授权码，再读取账号后保存。移除上游两个 ID、跨 ID 刷新重试及共享 verifier；旧凭据和不同 Client ID 的凭据均需重新登录，刷新只使用当前平台对应的自有 ID。复用既有令牌续期与账号存储；AniList 和 MyAnimeList 共用 `TrackerOAuthBrowser`，macOS 与手机使用系统授权会话，Windows／Linux 使用外部浏览器及应用协议回调，按各服务回调主机分发。临时监听在成功、失败、释放或十分钟超时后取消，不保留旧桌面 HTTP 回调或借用移动端 ID 的分支。额外开销为本地随机数、校验与登录期间的桌面订阅，无新后台请求；性能未专项测量。

Simkl 使用自有 Client ID `c2c74e7a95db1444f40967d2a7757cf3a7aeac83ae581f40de7410a219a03b63`，按 [AUTH V2](https://api.simkl.org/api-reference/oauth2-authorization-code) 使用 S256 PKCE、独立 state、固定回调与 `iss=https://simkl.com` 校验，请求并核对 `media:read media:write` 权限，再读取账号后保存。V1 身份、密钥及桌面 HTTP 回调已移除；旧凭据直接清除并要求重新登录，不做迁移。API 请求携带自有 `client_id`、`app-name=nodelane-comics` 与实际安装版本。浏览器复用 `TrackerOAuthBrowser`，账号沿用客户端现有存储与串行写入队列，无新后端或授权框架。

Simkl 到期按需续期，同一客户端进程内各页面共用一次在途续期；401 先重读最新令牌，必要时续期并最多重发一次，网络错误或未知写入结果不自动重发。临时服务故障保留会话，明确失效的授权要求重新登录；退出、切换账号与释放后的迟到结果不回写。搜索、发现、书单和进度同步沿用现有路径。增加的开销为 PKCE 本地计算、到期时的续期请求与仅在续期期间存在的 Future；未做性能实测。仅替换 Client ID 无法满足 V2 的权限及令牌生命周期要求。

Trakt 手机与桌面登录入口已隐藏，失去入口的旧登录、换码及回调代码已移除，续期不再携带上游密钥或重复尝试同一 Client ID。书单、推荐、观看顺序的业务实现和本地记录保留；当前缺少自有凭据，相关网络功能尚不可用。没有新增旧会话兼容、迁移或请求拦截逻辑。桌面同步仍使用 `http://localhost:48765/callback`，自有同步服务的回调登记待处理。

本地测试覆盖导入分发、重复／失败释放、NodeLane 模拟 PKCE，以及 AniList／MyAnimeList／Simkl 的回调校验、身份隔离、重试与迟到结果丢弃；桌面监听释放、超时、MyAnimeList 五个平台的身份选择、三种 Client ID 的恢复续期及拒绝后的单次请求均经模拟测试。匿名请求可进入 AniList 登录页，尚未完成真实账号授权。Windows 注册仅作静态核对，桌面回调仅模拟测试，不代表原生唤起通过；iOS 实机登录待验收。Android 已检查声明、纯 Dart 逻辑及模拟器中的回调入口解析，真实账号授权与真机登录仍待验收。

## 翻译与账号设置

- 更多首栏摘要打开 `MobileNodeLaneAccountPage`。已登录摘要只在 17 点账号名下显示一行 `Free`／`PLUS`／`Pro`，沿用 14 点次要文字、`muted` 色和 4 点间距，移除重复小徽章与套餐副标题；未知套餐保留服务返回名称，不能显示成免费账号。详情页保留原订阅名称、免费账号的“暂无有效订阅”说明及日期。账号默认头像使用独立 NodeLane 品牌资源；未登录页保留说明与登录主按钮，经系统浏览器完成原生 PKCE 登录，进入页面不自动登录。已登录详情显示名称、可复制 ID、订阅状态／到期／续费与三类额度。接口没有邮箱或头像，不添加虚构字段。
- 官方渠道内的 `NodeLaneAccount` 解析现有 `GET /v1/me` 和 `GET /v1/billing/status`，不发起购买或计费变更。官网管理／订阅方案通过系统浏览器打开固定公开地址，不传递应用凭据；返回应用后刷新一次。
- 免费、订阅与购买额度分开表示可用、已用、处理中页数，不合并总额。不限量、未开通、未知与零分别表示。额度明细就地展开三个平级卡片，不发起请求。账号读取与刷新只更新现有信息，移除“正在读取账号”提示、页尾额度说明和更新时间；失败仍保留同账号快照与重试入口，缺失字段不伪装成免费或零。
- 多处视图共享服务和一次在途读取；退出、换号和释放取消读取、清除快照并拒绝迟到结果。续费查询失败仍展示成功读取的账号与余额。刷新不替换阅读运行时、不改变原译图或位置；无后台轮询。
- 阅读器和网页的登录操作关闭原弹层后进入同一账号页。目标语言共用 `TranslationLanguageRow` 和统一弹层；四个已有选项保持不变，当前项打勾，取消／同值不写入，新值仍由原服务保存并替换运行时。
- 手机翻译语言位于更多首页及阅读器／网页面板，译图清理移至存储与备份；桌面／电视仍使用原设置视图。登录、退出、语言与清理继续由 `TranslationService` 负责，防止重复操作，初始化错误不显示底层信息或提供无效重试。

## 下载队列

[下载队列统一设计](design/ios-download-queue-concept.png)由内置 image_gen 生成，覆盖队列、任务操作抽屉、失败重试与空队列四种状态；[生成提示词](design/ios-download-queue-concept.prompts.txt)记录原始输入。手机页面已按该稿替换，字号、图标、圆角、按钮点击区与安全区以统一令牌和基础组件为准。

- 基于 `DownloadQueueScreen` 和原下载仓库已有能力：显示章节进度、拖动调整顺序、开始／重试队列、取消单章或本作品所有排队章节、进入下载设置。不增加暂停、速度、预计时间、完成历史或逐项重试。进度只展示原数据可计算的百分比，不把计数当成图片张数或字节数。
- 复用 `nodeLaneAppBar`、`NodeLaneIconButton`、`NodeLaneGroupSurface` 和统一主题的 `FilledButton`，不另建基础按钮或卡片。顶栏两侧均为 44 点点击区；卡片采用 18 圆角、16 内边距、20 页面边距、12 卡片间距，正文 16、辅助文字 13–14。进度条为 3 点，失败用错误色，其余进度与主操作用强调色。零进度显示等待，原记录有开始标记且有进度时显示下载中。
- 菜单位于卡片右上，44 点拖动区位于右下，整个区域可命中。标题与排序提示在常规宽度左右对齐，大字号或窄屏改为上下排列；主按钮固定在底部安全区上方，启动处理中禁用重复提交、菜单与拖动。
- 任务菜单复用按内容高度展开的 `NodeLaneCatalogSheet` 和破坏性 `NodeLaneRow`，书名与章节说明位于标题下方。关闭不操作队列；返回选择后以最新待处理列表和回调核实任务，已完成或被移除的任务不再取消。空态在完整内容宽度内居中；不添加没有实际入口的新建下载操作。长文案可滚动，底部只保留正常间距和安全区。
- `MobileDownloadQueue` 仅组合展示与动作入口；排序、取消、排队状态和失败重试仍由原页面与仓库负责。复用组件不新增请求或状态流，保留列表按需构建；性能未专项测量。仅修空态对齐更轻，但不能统一旧菜单与卡片控件。

## 外观设置

- 外观页首行显示应用语言，下面按主题、界面和日期显示分组。更多首页搜索“显示语言”或“display language”可直接打开语言选择页，仍复用原有控件与 provider。跟随系统／浅色／深色合并为一个主题入口；纯黑只在深色下显示，启用时隐藏混色滑杆，保留原混色值。主题和配色写入仍调用已有 provider。
- 配色、语言和字体使用可搜索的全屏选择列表，保留全部原选项。字体列表只展示名称，不为预览加载字体；明确选择默认字体与取消页面分别处理。当前项有勾选，取消或选择当前值不写入。
- 界面缩放保留原 85%–125% 范围，拖动即时预览，仅在结束时持久化。相对时间戳和日期格式保留原规则，设置行右侧显示当前格式，选择页保留日期示例。导航定制沿用原路由，手机布局见下节。
- 选择列表按需构建，搜索区共用 `NodeLanePinnedHeader` 吸顶容器，为键盘、短屏和既有大字号回归保留可访问空间。选择页面只回传选项；外观页面负责连接原设置回调，不新增设置状态或存储逻辑。
- 顶部仅已下载／隐身状态条已移除，删除 `ModeBarsLayout`、两种旧状态条、专用字体及对应布局测试。页面直接使用原系统安全区，不再因模式切换增加高度；更多中的开关、模式持久化、下载筛选和隐身行为仍沿用原 provider。

## 通用设置与导航定制

- 通用页按书架、应用设置和高级分组。自动更新行始终显示当前频率（含“从不”），使用已有全屏选择列表；取消或选择当前项不写入。关闭自动更新时隐藏仅 Wi-Fi 开关，保留原偏好，重新开启后恢复显示。双击搜索提示保留；导航定制从外观进入，欢迎引导重播从关于与帮助进入。
- 网络与推荐权重默认收起，展开仅显示控件；Discord 设置暂时隐藏。DoH 使用独立开关，展开网络分组不会启用服务；服务选项、自定义地址、DNS、用户代理和 Cloudflare 代理仍写入原 provider／store，保留原校验规则。地址行最多显示两行，完整内容在编辑弹窗中查看。
- 文本弹窗可滚动，键盘上方保留取消与确认；取消和明确保存空值分别处理。控制器随弹窗释放，不在发起方提前销毁。推荐权重沿用四个原字段，拖动结束时保存，重置仍使用原默认值；内存显示保留原回调及平台能力边界。
- 导航行使用本地化标题、独立拖动区和自适应开关，保留原顺序字段、媒体身份与隐藏偏好。浏览和更多始终显示；漫画、动画和小说仍合并为书架入口，多余底栏入口仍由更多页承接。原电视布局开关保留在高级分组。
- 手机排序写入新列表，按当前 Flutter 拖动回调提供的目标索引移动，不修改旧偏好列表。启动顺序仅在创建路由器时读取，排序不再重建路由器或丢弃当前设置页；已有主页面监听偏好并更新平台底栏，重启使用保存后的首个可见入口。

## 安全设置与锁定页

- 手机安全页使用分组开关和独立说明，明确区分检查设备能力、可用、不可用和验证中的状态。检查或验证期间禁用操作，失败或取消保留原值并显示简短反馈，不展示底层异常；开启与关闭均须原系统认证成功。
- 锁定页以锁图标、状态和一个解锁按钮为主，短屏与大字号时可滚动，按钮避开系统安全区。页面保持不透明，阻止点击穿透，并从 Flutter 辅助功能树中屏蔽下层内容；无关闭或跳过入口。
- 两个手机视图只接收状态与回调，继续由原 `LocalAuthentication`、设置 provider 和应用生命周期监听负责认证、持久化及后台锁定。保留设备密码回退与后台返回继续认证的原参数，不新增密码、凭据存储或认证服务。重复点击只保留一次认证，页面离开后不再应用迟到结果。
- 桌面与电视保留原布局，共享认证回调的重入和挂载保护；中英文提示去掉固定品牌名称，说明按可用宽度换行。

## 下载设置与队列

- 下载设置按网络、数据与存储、本地文件夹分组。并发关闭时隐藏数量入口并保留原值；数量和延迟使用锚定当前行的浮动滚轮，沿用 1–255 和 0–120 秒范围，停止滚动后保存，点击外部关闭。Wi-Fi、CBZ 和读后删除继续写入各自的原 provider。
- 文件夹默认收起，展开可查看和选择完整路径，自定义目录才提供移除入口。移除仍需原确认流程，只更新目录配置；打开页面和展开目录不触发扫描。默认路径在页面内只读取一次，各文件夹展开状态与路径文字滚动状态分别保存。
- 目录选择沿用现有平台入口，同一时间只打开一个选择器；iOS 取消后直接返回，不再触发第二个选择器。文件夹命名、移除和格式说明弹窗支持滚动；格式说明保留原目录树与支持格式。
- 队列使用按需构建的可变高度卡片，显示漫画、章节、进度及失败状态；拖动区、单章取消和整部取消分开。底部固定开始／重试，入队期间禁用重复操作，空队列给出添加提示和下载设置入口。没有增加暂停状态或逐行重试协议。
- `DownloadQueueScreen` 继续拥有原订阅、排序、取消及下载处理回调，新手机视图只接收数据和事件。桌面与电视保留原布局，下载服务、队列持久化和扫描逻辑未改。

## 浏览设置与清理

- 手机浏览设置按扩展库、更新、全局搜索、内容显示和高级分组。三类扩展库沿用原媒体身份和路由；iOS 保留扩展服务入口，Android 保留原直接使用扩展的入口规则。
- 第三方的检查更新与自动更新相邻显示；关闭检查时隐藏自动更新，保留原偏好。官方插件固定自动安装和更新，不提供开关。18+ 来源默认显示，新建配置与数据库／备份缺失值共用同一默认值，已保存的关闭选择保留。置顶来源、内容显示与开发者模式继续各自写入原 provider；开发者模式不会随高级分组展开而改变。
- 数据清理工具默认收起，展开只展示入口，不执行查询或清理。清理来源、非书架记录、本地书架继续使用原确认说明；清空书架改为勾选漫画／动画／小说，初始不选中，至少选择一类才能确认，省去输入英文类型名。
- 手机确认弹窗可滚动，操作按钮按可用宽度换行。确认后等待原 repository 操作完成，期间禁用重复确认、选择、取消和普通返回；成功才关闭并显示原完成提示，失败留在弹窗中显示简短反馈，已选类型保留。弹窗释放后不再导航或更新显示，不展示底层异常。查询条件、删除范围、同步与磁盘文件处理规则未改。

## 扩展服务设置

## 在线字幕服务

- 设置入口位于「播放器 → 内部播放器 → 在线字幕服务」，播放中的字幕搜索面板也可进入。默认关闭，用户可选择个人 Wyzie Key 或自有服务；未配置时不发起作品或字幕搜索。关闭并保存会清除已存地址和凭据，内嵌字幕、片源字幕及本地文件加载继续保留。
- 个人 Key 直接访问 `https://sub.wyzie.io/search`；自有服务使用用户填写的完整 HTTPS 搜索地址和可选 Bearer 访问令牌。两种方式只保存当前选中的配置，返回取消不写入，保存失败保留草稿。地址和凭据使用设备私有安全存储，不进入普通设置、应用导出备份或默认日志；保存配置不代表服务已验证可用。
- 自有服务目前须遵循 [Wyzie 搜索与下载协议](https://docs.wyzie.io/subs/usage/direct)：接收 `GET <搜索地址>?id=<IMDb作品ID>&encoding=utf-8`，剧集同时带 `season`、`episode`；返回 JSON 数组，条目包含 `url`，以及 `media`、`language`、`display`、`format`。下载地址应直接返回 UTF-8 文本字幕，可为相对路径或 HTTPS 地址；支持 SRT、ASS、SSA、VTT、SUB、TXT。接口地址不含查询参数、片段或内嵌凭据，访问令牌单独填写。同源下载可使用该令牌，跨域文件使用响应自带的签名链接，不携带服务令牌；请求不自动跟随重定向。
- `SubtitleCatalog` 独立负责 IMDb 作品和剧集发现，`SubtitleSource` 负责字幕搜索与内容读取；Wyzie JSON、Key 参数和自有服务鉴权封装在适配器内。播放器只接收字幕文本与语言等元数据，通过现有 `SubtitleTrack.data` 加载，不接触 Key 或签名下载地址。本地下载在章节字幕目录中完整写入后替换同名字幕，保留实际文本格式。
- 配置变化会销毁旧服务实例、取消请求并清空旧搜索结果；关闭面板释放请求，迟到结果不更新已离开的界面。搜索、选择和下载期间阻止重复操作；鉴权失败、额度用完、连接失败和异常响应分别提示，只由用户显式重试。每次请求限时 30 秒，元数据最多 2 MiB、字幕文件最多 8 MiB；没有后台轮询或跨配置结果缓存。实际内存、耗电及播放效果尚未实测。
- **未来 NodeLane 接入**：由 NodeLane 账号层从云端获取当前用户自己的字幕服务凭据，再在 `subtitleSearchServiceProvider` 装配对应 `SubtitleSource`；凭据按服务地址与账号 ID 隔离，切换账号、退出或凭据变更须销毁旧实例和结果。不得使用应用统一 Key，也不让播放器依赖翻译渠道或账号认证协议。云端字幕凭据的接口、刷新与撤销协议尚未实现，因此本轮不展示可选的 NodeLane 来源，不新增空实现或虚构接口。
- 仅将固定地址改成设置字段更轻，但不能隔离播放器、供应商协议和未来账号凭据获取；当前只拆分字幕契约、适配器、设备配置与装配入口，没有新增通用渠道框架。验证覆盖模拟请求、配置恢复与替换、失败后的显式重试、重复操作和迟到结果隔离；真实 IMDb／Wyzie／自有服务联调、原生字幕播放和下载目录访问仍需验收，Android 运行验证继续暂缓。

备份与恢复视图只增加当前操作标记、密码草稿和本次冲突选择；离页后释放，不保留密码控制器或新增任务。未匹配来源按媒体类型各读取一次，选项和冲突列表按需构建，沿用已有设置订阅和缓存大小查询。仅调整旧弹窗尺寸会更轻，但仍难以浏览大量冲突与搜索来源；真机恢复大备份时的内存、耗时和耗电尚未专项测量。

来源维护复用设置选择器，仅新增操作草稿、搜索控制器和忙碌标记；离页后释放。来源及重复列表沿用入口时的原查询结果，按需构建行，不引入逐行订阅；回滚页共享原快照 provider，无轮询。只放大旧弹窗更轻，但无法提供长列表搜索及可滚动的完整删除选项。原重复查找、备份和数据操作的耗时及内存尚未在大书库真机专项测量。

统计与分类各订阅当前媒体，分类详情复用同一 provider；没有逐行订阅，记录副本、排序草稿及名称控制器随操作或页面释放。日历仅持有焦点日期、选中日和视图格式，切换日期／月份不会调用父页预测查询；原书库流更新时逐本读取最新章节的行为保留。列表按需构建，日标记最多三个，不新增调度器、轮询或缓存。只调整旧卡片尺寸更轻，但无法改善分类图标含义、固定统计图裁切和未构建日期行不可定位的问题；真机性能和大书库查询开销未测量。

错误列表按需构建卡片，沿用原更新错误订阅和可见条目的漫画查询；报告列表沿用原页面读取与排序，没有新查询流或后台任务。完整文本和堆栈仅在展开时创建，视图状态随页面释放；不加载额外封面或建立诊断缓存。只增大旧行高改动更少，但不能显示完整错误或解决堆栈横向阅读负担；大量错误、长堆栈和真机内存开销尚未专项测量。

### 待解决问题与验收

- macOS torrent 兼容暂缓：应用声明最低 macOS 12，但既有 torrent 动态库声明最低 macOS 26。后续需确认实际支持范围并统一系统版本要求，验证较旧系统的启动与播放；目前不能按宿主声明承诺支持 macOS 12。
- 日历格式切换的控件测试仍触发 `Build scheduled during frame`，不计入通过范围。
- 轻点进度条后切换阅读方向有偶发回退首页，完整拖动未复现，仍需定位。
- 本地包仅支持在当前 iOS 沙盒中按相同相对路径恢复已有文件；临时文件被系统清理后的重装恢复及持久导入策略尚未验收。
- 界面预览通过不代表数据操作完成。迁移、下载、分类／书签、备份、追踪等写入应继续验证失败、重复执行、处理中后台恢复和进程回收。
- 发布前完成 iOS 真机、可访问性、长列表与图片资源测量、应用标识与签名核对；Android 完整功能与正式发行需独立验收。
