# 手机界面与视觉令牌

当前验收按用户最新要求限定为 **iOS 模拟器、常规字号**；停止超大字号专项适配与测试。Android 模拟器已退出，恢复 Android 联调前再处理其安装与样例清理。下文既有平台／字号记录为历史证据，不扩展本阶段验收范围。

当前优先漫画相关页面，以及漫画书架的操作菜单与弹框。小说和动画暂停专项改造；既有实现保留，后续待办按漫画使用流程排序。

逐页替换手机视图，已落地书架、平台导航、浏览与来源管理、全局搜索、来源内漫画列表、迁移搜索与确认、批量迁移、扩展详情、历史与更新、更新错误与错误报告、关于与应用更新入口、欢迎引导、漫画详情与目录、阅读工具栏与弹层、多标签浏览器、更多与设置入口、翻译与账号设置、外观及通用设置、安全设置与锁定页、下载设置与队列、浏览及扩展服务设置、全局漫画／小说阅读与听书设置、小说阅读内控件与听书面板、播放器通用／音频／解码设置、播放设置弹层、自定义按钮与 MPV 配置、同步与追踪设置、账号及条目管理、追踪编辑与搜索、备份／恢复与存储、回滚记录与来源维护、统计／分类／日历、导航定制和全局模式提示。沿用现有来源、书库查询、筛选排序、导入、阅读、下载和批量管理逻辑。桌面与电视入口继续使用现有布局。后续页面按此文逐项收敛，不另建业务状态或迁移漫画数据。

## 视觉方向

参考 NodeLane 插件端书架的信息层级：大封面、来源与阅读状态、直接导入、搜索和批量操作。手机使用平静的纸面和轻边框，避免将桌面的粗描边、硬阴影和大横幅照搬到小屏。仅参考布局和语义，独立实现 Flutter/UIKit 视图，不复制同级 GPL 仓库源码或漫画封面。

| 令牌 | 手机约定 |
| --- | --- |
| 画布／表面 | 浅色近白纸面、深色炭灰；书籍封面保持原色 |
| 文字 | 系统字体，大标题 32、书名 15、正文 16、辅助信息 12；遵循系统文字缩放 |
| 强调色 | 默认 NodeLane 蓝；继承已有用户主题的强调色，不改变状态色含义 |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24；手机页面边距 20 |
| 圆角 | 控件 12、封面 14、容器 20；清晰层级，少量阴影 |
| 点击区 | 至少 44 pt；正文不压在封面上；长按继续批量选择 |
| 动效 | 短暂状态过渡；尊重减少动态效果，不新增常驻动画或整页模糊 |

## 导航与书架

- 手机底栏把漫画、动画、小说归入一个“书架”入口；书架标题下选择媒体类型。保留现有媒体隐藏偏好、导航顺序、路由和角标。其余默认入口为更新、历史、浏览、更多；超过五项时通过更多入口展开，不挤压按钮。
- iOS 使用嵌入式 UIKit `UITabBarController`，由运行中的系统绘制外观、材质与辅助功能。当前系统采用 Liquid Glass，较旧系统使用其原生外观。不用 Flutter 模糊胶囊冒充原生底栏。
- Android 使用统一令牌的底栏：实色表面、轻边框、明确的选中状态，保留系统返回与安全区。
- 书架常用操作直接可见：标题、媒体切换、导入、搜索、筛选。更新、随机阅读等次要操作保留在菜单；选择模式继续使用既有批量操作。
- 网格默认自适应两列，已有列数在可用宽度范围内生效，保留网格／仅封面／列表模式；书名放在封面下方，来源与状态尽量单行。继续阅读调用既有入口，不为视图增加逐本历史订阅。
- 空书架提供导入与浏览入口；筛选无结果明确提示调整筛选，不把用户已有书籍误报为空书库。

原生参考：[Apple Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)、[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[UITabBarController](https://developer.apple.com/documentation/uikit/uitabbarcontroller)。

### 漫画书架操作

- 手机漫画书架的更多操作统一为底部弹层，展示更新／停止更新、随机打开与搜索时忽略筛选。无条目时禁用更新和随机打开，运行中的更新仍可停止；开关说明保持完整。弹层由根导航打开，覆盖书架分支外的 UIKit 底栏。选择后继续交给原有回调，随机打开只抽取索引，不再重排被订阅的书架列表。
- 长按选择沿用原选择状态，底部给分类、标为已读、标为未读、迁移和移除添加文字；全选／反选提供辅助功能名称。操作栏隐藏时退出点击与辅助功能命中，保留安全区。小说、动画及桌面／电视继续使用原布局。
- 移除确认固定打开时的现存漫画范围，显示数量和可展开的完整名称；名单按需构建，并限制可视高度。书架记录与下载文件分别勾选，默认均不选；本地导入说明会删除的记录及压缩包。取消保留当前选择，处理中禁止普通返回和重复提交；失败提示可能已部分处理，只能关闭并核对，不能在同一弹框中再次写入。
- 文件与记录处理继续复用原操作。本地文件先于其章节记录删除，两项同时勾选也只移除一次记录；失败停止后续条目，不增加自动重试、事务或恢复协议。新增开销是本次所选对象／名称快照及少量视图状态；未测量内存或帧率。仅给旧菜单改色更轻，但无法容纳清楚的操作说明与删除范围，因此采用独立视图，不新增全局菜单或任务管理层。

### 漫画书架筛选、排序与显示

- 手机漫画书架使用固定标题／关闭入口和三个可切换分区，内容独立滚动并保留各自位置。面板从根导航打开，覆盖原生底栏；不再提前构建所有内容测量弹层高度。小说、动画、桌面与电视继续使用原设置弹层。
- 六项筛选直接选择“不限／包含／排除”，仍写入原来的三态字段，按钮辅助功能名称带上对应条件。设置沿用即时生效的规则；书架查询、已读判定和下载判断没有改动。
- 来源选择使用可搜索的本地草稿，搜索不清除被隐藏的选择；取消丢弃草稿，重置只清空草稿，确认才写入原来源筛选字段。未选择表示全部来源，确认前过滤已经不可用的来源；沿用已有来源名称匹配，不引入新的来源身份或合并规则。
- 七种排序条件与升／降序分开操作。重新点选当前条件不再暗中改变方向；回调读取当前 provider 状态，拒绝旧回调引起的重复反向切换。排序比较与未读数量规则继续沿用原实现。
- 显示分为模式、徽章和布局：保留四种原显示模式、默认及 1–7 列偏好；列数继续由现有书架布局按屏宽限制，只在拖动结束时持久化，列表模式隐藏列数控件。徽章、继续阅读、分类标签及项目数沿用原字段，其中来源徽章仍是原有全局开关。面板复用已有设置与书库流读取最新快照，不新增查询、存储层或全局草稿。
- 新增开销主要是三个分区的控件和一份来源名称选择集合，来源结果按需构建；未测量内存或帧率。仅给旧循环勾选图标增加提示更轻，但仍需多次点击才能选定排除状态，因此手机采用显式选项。

### 漫画导入与分类弹框

- 手机漫画导入明确显示原文件选择器支持的 ZIP／CBZ，选择取消后留在弹框并可重新选择。处理中禁用重复选择和普通返回；导入失败提示先核对可能已加入的漫画，只允许关闭。继续使用原文件选择器、解析和逐文件写入，返回文件数量仅用于区分取消与完成，不增加导入任务或重试机制。
- 分类弹框显示操作对象及替换规则，保留管理、取消和保存入口。短内容随内容收缩，长列表限制高度并按需构建；读取中、读取失败和无分类分别显示。管理入口先关闭选择弹框，再进入原分类页面，返回仍保留书架选择。
- 分类选择仅保存本地草稿。批量初选在打开时取得全部对象的分类并集，不再依赖可见行初始化；批量仍以勾选的可见分类统一替换原分类。单本已收藏漫画保留已有隐藏分类，新收藏可选择隐藏分类，保存时过滤已不存在的分类。
- 保存从现有仓库读取最新漫画，复制后仅更新分类及原收藏字段，并等待原写入完成；成功后才退出批量选择。处理中拒绝重复提交和普通返回，失败后提示核对而不在同一弹框重试。新增开销是分类草稿和本次保存对象副本，无新存储或全局状态；资源开销未测量。只调整旧弹框样式改动更少，但不能修正取消与完成混淆、惰性行漏选和未等待写入的问题。
- iOS 本地压缩包若仍保存旧沙盒绝对路径，读取时先保留可访问的原文件；原文件不可用时，只核对同一应用容器父目录下、当前沙盒中相同相对路径的文件，且只接受 Documents／Library／tmp。存在才使用，不改章节记录、不移动文件或按名称搜索其他目录。用于处理安装更新后沙盒目录变化，不能恢复已被清理的文件。

## 欢迎引导

- 手机按“选择内容 → 添加阅读内容”两步展示，取消旧的分开／合并底栏问题：当前手机书架已经统一，旧导航偏好不再由手机引导写入。第一步保留至少一种媒体，说明在书架顶部切换；恢复备份仍是独立入口。桌面与电视保留原步骤及布局。
- 两步进度有辅助功能名称，标题和说明随内容滚动。下一步、继续或跳过放在底部安全区，键盘出现时仍可达；不同步骤分别保存滚动位置，返回不清空扩展库地址。手机视图只接收状态和回调，不加载预览导航平台视图。
- 第二步把扩展库与本地文件夹分组，媒体身份、地址校验、库解析、去重、持久化、扫描和恢复继续调用原流程。成功名称和目录完整换行；文件夹结果按需展开，沿用最多 40 个预览名称及剩余数量，不为预览读取封面或文件。
- 添加库、目录选择／扫描及恢复进行中禁止重复发起和切步；异步完成后先检查页面是否仍在。库请求保留开始时的媒体，失败保留地址；失败扫描不再显示成“未找到内容”。系统返回先交给恢复流程的内层弹窗，之后才退回引导步骤；iOS 目录选择取消不再弹第二个选择器。已交给原服务的扫描或恢复仍按原服务执行，视图不增加回滚或任务取消协议。

## 浏览与来源

- 将原来的六个横向标签改为“媒体选择 + 来源／扩展”两层；切换媒体时保留当前分区。已有跳转请求在浏览页保持挂载时也生效，隐藏媒体的设置即时同步，并按媒体身份保留选中项。
- 来源页保留全局搜索、来源内漫画列表、来源筛选、最近使用、置顶、语言分组和本地来源。来源卡片把标题与元信息放在上方，最新内容／置顶放在单独操作行，避免挤压长名称。
- 扩展页保留名称搜索、语言筛选、版本与仓库信息、安装／更新／设置及卸载确认。常用动作显示文字；仓库配置有直接入口，空结果可重置查询或前往配置，不增加推荐源或自动安装。
- 查询、来源身份、安装更新和仓库持久化仍由现有 provider／repository 负责。新卡片与页头只接收显示内容和回调；继续使用原 TabBarView 与按需列表，滚动位置按媒体和分区保存。
- 软件键盘显示时收起标题与分区，保留搜索和筛选；收起键盘后自动恢复。页头订阅实际视图尺寸变化，并保留外层安全区与文字缩放；短屏／横屏限制页头高度并允许滚动。媒体菜单与主要操作保持至少 44 pt 点击区。
- 来源筛选、语言列表和扩展库管理统一为轻背景、分组卡片和明确空态。筛选按原语言分组；开关、勾选仍写入原字段。无来源时可以直接进入对应媒体的扩展分区，无语言时可进入扩展库配置。
- 扩展库卡片分开显示名称、主机名、可见性开关和复制／浏览／移除操作；空库只展示一个添加入口，有库时将添加操作固定于底部安全区。添加弹窗支持长提示、大字体和键盘下滚动，移除确认显示目标名称；校验、下载解析、去重与持久化沿用现有流程。
- 弹窗控制器在退场动画结束后释放；刷新完成时仅更新仍挂载的页面。
- 扩展详情按“名称／版本／语言 → 来源设置 → 高级操作”排列，缩小原来占据首屏的大图标；图标加载沿用扩展列表的入口。设置写入、编辑代码、Cookie 清理和卸载仍调用原流程，卸载保留确认；开发工具仍只在开发者模式下显示。设置弹窗允许文字换行与键盘下滚动，按钮交给弹窗自行换行。

## 全局搜索

- 手机使用常显搜索框与明确提交按钮，搜索范围和已提交关键词放在结果上方；编辑草稿不联网，不清空当前结果。保留初次打开与清空时读取来源热门列表的规则，预填关键词只作为初值，清空后不会回到旧词。键盘与短屏下搜索区可滚动，结果独立滚动；桌面与电视保持原布局。
- 来源标题与语言完整换行，结果仍按来源分组横向浏览。每行高度随封面宽度和文字缩放计算，标题保留两行及完整辅助功能名称。手机使用轻量书库角标，不再把整张封面变暗；空封面直接显示本地占位，图片加载或请求头解析失败不阻挡标题和操作。打开详情、长按快速收藏和原收藏匹配规则保持不变，不合并来源身份。
- 空结果与失败来源仍集中折叠，手机展开后显示完整原因并保留原来源搜索入口。无可用来源时区分未安装、仅置顶和内容过滤，分别提供扩展分区或浏览设置入口；设置返回后重新读取原筛选，不新增搜索范围配置。
- 新查询直接切换，不先发一轮热门请求；按轮次丢弃旧空结果回报。排队项拿到并发位后先核对页面是否仍在，已离页的不再读取服务；并发位直接交给下一项，避免交接瞬间超出原三路上限。已经启动的来源请求仍由原服务处理，页面不承诺撤销。

## 来源内漫画列表

- 手机使用常显搜索、明确提交及热门／最新／筛选入口；编辑搜索草稿保留当前结果。来源备注可展开完整阅读，显示模式、保存搜索、已保存搜索、浏览器和来源设置集中在更多页，沿用原请求、路由与按来源保存的关键词。
- 舒适网格使用下方标题，紧凑网格保留封面内标题，列表保留封面与名称。列数沿用原媒体密度设置并限制手机最小卡片宽度；结果按需构建，关闭卡片自动保活，分页状态占完整一行。已有书库记录仍通过原单个来源订阅匹配；点按详情、长按收藏及来源身份规则不变。
- 手机空封面不请求远程白图，图片或请求头失败显示本地占位，自定义封面按显示尺寸解码；旧列表的图片失败也限制在固定封面尺寸内。沿用现有网络缩略图缓存，不引入独立图片缓存或站点处理。
- 搜索、清空及切换热门／最新重置分页状态；来源响应按当前查询轮次接收，旧翻页结果与失败不混入新查询。追加失败保留已有结果，只由明确重试重新请求该页；空末页更新结束状态；本地来源按原 50 条页长判断尾页，空列表不再显示加载更多。一次返回全部数据的来源每次只增加最多 50 项的展示窗口，不再请求下一页；完整元数据仍由原服务返回并保存在当前页面，退出后释放。
- 筛选页编辑独立深拷贝草稿，返回取消不改已应用条件；确认、重置继续使用来源的原筛选类型与默认值。长选项使用现有选择页，键盘避让与文字控制器生命周期由视图处理；没有新增筛选存储层。切换热门／最新恢复默认条件，避免后续关键词查询暗中带入旧筛选。

- 当前章节只关闭目录，其他章节先回传给仍有效的阅读器，再使用原路由替换入口。重复选择、已离开的入口和阅读器已切换章节时的迟到选择不再导航；切换前重新核对目标记录及所属漫画。书签通过原写入队列的事务更新最新记录的书签及更新时间，不覆盖最新阅读进度，也不重建已删除记录；关闭目录时重新读取当前章的书签图标。
- 书签写入完成前禁用选择、重复写入和普通返回，面板不以拖拽手势关闭；失败保留原显示并提示关闭后核对，不自动重试。搜索控制器、偏好覆盖和列表控制器随面板销毁释放。新增开销为本次目录快照的搜索结果、少量书签显示值和操作时的记录读取，未引入新的服务或持久层；真机开销未测量。只改原列表外观更轻，但不能解决同名章节定位、短屏搜索和弹层销毁后导航的问题。

### 漫画图片操作

- 手机漫画长按图片立即打开有界底部菜单，固定标题和关闭入口，完整书名、图片所属章节及从 1 开始的页码随内容滚动。保存、分享、设为封面分别显示用途；明确作用于原始整页，不包含翻译、分割裁剪或阅读滤镜。相邻预加载章节使用图片自身的章节信息，过渡页不打开菜单。
- 图片字节复用原压缩包、本地文件或缓存读取；加载失败可以明确重试，同次只读一次，关闭后忽略迟到结果。菜单不解码预览、不新增下载或翻译请求；保存沿用原文件名规则、扩展名识别与存储路径，iOS 明确为当前应用存储位置的 Pictures 文件夹，Android 为 Pictures/Mangayomi。
- 保存成功显示“图片已保存”并禁用本次重复保存；分享调用原系统入口，返回后不将取消当成成功发送。任一操作等待时阻止重复触发和普通返回，菜单不以拖拽关闭；异常提示关闭后核对，不在结果未知时自动重复执行。路由已离开时不更新界面或误退下一页。
- 设为封面沿用小于 5 MB 的限制，超限仅禁用封面操作；确认在同一面板内显示完整对象，取消回到操作列表，不重读图片。确认通过既有漫画仓库写入队列更新最新记录的封面与更新时间，保留期间改变的其他字段；记录已删除则报错，不重新创建。调整仅限手机漫画阅读器，其他媒体和平台继续使用原共享入口。
- 新增开销为一个菜单、三个操作及当前图片字节引用；文件读取与写入、系统分享沿用原能力，关闭后释放菜单状态，不新增持久层或图片副本预览。真机内存及耗时未测量。仅给旧图标补文字更轻，但无法同时交代原图范围、保存去向和封面确认，也不能处理等待期间的重复操作。

### 漫画详细阅读设置

- 阅读模式页先显示完整书名和单本说明，再提供当前漫画模式；连续模式下显示自动滚动及原 2–30 速度范围。全局部分明确用于所有漫画并即时保存，裁边常显，页面布局与连续阅读选项按需展开；不适用于连续模式的横屏缩放和放大后导航继续隐藏，隐藏不清除原值。
- 通用页保留原缩放、背景、页码、屏幕常亮和翻页动画；导航与闪屏选项收进独立展开组。布局、连续阅读、导航、闪屏、选择行和滑杆从全局设置页面提取为共享视图，继续使用同一批 provider；阅读器不额外展示目录滑动动作。边距、闪屏和自动滚动速度只在松手时保存，选择页取消不写入。

- 打开设置暂停自动滚动，进入选择页或改变模式期间继续保持暂停；关闭时仅在阅读器仍存在、当前为连续模式、开关开启且需要恢复时继续。重复选择与关闭只返回一次，阅读器离开后不应用迟到选择或恢复滚动。自动滚动保存改为在原写入队列内合并当前漫画记录，保留其他漫画和全局偏好；没有新增定时器或存储层。
- 新增开销为当前弹层、分区滚动位置和滑杆草稿；展开组复用已有偏好订阅，不增加图片解码、网络或缓存。真机开销未测量。仅重排原长列表更轻，但会继续混淆单本与全局作用范围，也无法处理设置未关闭时提前启动滚动的问题。

| 网页原位翻译 | 明确地址入口、少量常用标签操作、普通图片／可读 Blob、前后台位置恢复 | 已有有界多标签与桥接；需提供不依赖安装扩展的可发现入口，并验收 WKWebView。承诺范围以架构支持矩阵为准，不能宣传“所有网站可翻译” |
| 结构化来源 | 只推出少量经过授权与 iOS 验证的来源，保留单来源身份 | 复用适配契约，不重写全站。来源名单、随包固定规则及分发方式是待完成项；未通过的来源不列入受支持清单 |
| 更新与离线 | 收藏漫画的手动更新、明确选章下载、队列暂停／取消、已下载原图离线阅读 | 原服务已有；需真实来源失败恢复与磁盘不足验证。离线状态不能发起云翻译，不承诺清理后仍有全部译图 |
| 软件账号与基础保护 | 更多首栏登录／退出、会话恢复、隐私说明、可用的账号删除入口 | 账号卡片已实现；账号删除能力需核对现有后端契约。首次启用云翻译说明上传当前漫画图片，账号凭据继续留原生侧 |
| 数据与反馈 | 手动备份／恢复、缓存与下载占用、独立版本信息、问题反馈及第三方声明 | 保留数据可带走能力；备份明确包含的书架／进度范围，不承诺含原始漫画文件、登录凭据或私有翻译缓存 |

网页版翻译与结构化来源分别验收。若少量来源的打包或授权尚未就绪，可先在明确缩小范围的测试包验证“本地漫画＋网页翻译”，不能把该测试包标为来源功能完整的正式版。

### 精简与延期

| 范围 | 首版处理 | 理由与实现边界 |
| --- | --- | --- |
| 动画、小说、播放器、字幕、听书、BT | 从首版导航、导入选项、搜索和设置移除；停止对应启动初始化 | 与漫画翻译主线关系小，视频依赖已造成 iOS 架构／签名构建负担。先切断入口与初始化，再验证并剥离首版不需要的原生框架；保留旧数据和上游源码追溯 |
| 第三方追踪、追踪书库、跨设备同步、扩展服务器 | 延期公开，关闭首版对应自动刷新／服务启动 | 多套账号与失败状态扩大验收面。NodeLane 登录不得暗示已实现云同步；手动备份继续保留 |
| 任意扩展仓库、创建／编辑脚本、自定义执行按钮 | 首版发行包不开放相关执行通路，随包固定已选适配逻辑 | 源码与内部开发工具可保留；不能只藏按钮仍接受深链、备份配置或启动任务重新启用，也不以远端开关在审核后恢复 |
| 统计、日历、复杂导航定制、批量迁移 | 延期主产品入口 | 历史与基本分类保留；已有非漫画数据不删除，停用能力不得触发迁移或重写书库 |
| 阅读高级项 | 默认只呈现方向、模式、亮度和基础外观，其余收进“高级” | 已完成的裁边、双页、滤镜等不必重写或删除；不再为全部组合扩展首版功能范围 |
| 自动滚动、跨来源聚合、更多格式、复杂站点、其他翻译渠道、本地模型 | 自动滚动放高级且默认关闭；其余延期 | 不扩大现有翻译格式／站点承诺，避免首版再承担模型下载、推理、跨来源身份和全站适配 |
| 购买、充值、会员营销界面 | 测试版先不新增，建议采用受控免费测试额度 | 正式版的收费与已有付费账号权益使用方式需先确定；隐藏购买入口不能直接视为满足商店规则 |
| Android、桌面、电视、iPad 专项体验 | 暂缓开发验收与发布承诺 | Android 代码保留但当前不跑构建、模拟器或真机。iPad 是否作为支持设备须在发行配置中明确，不能声明支持却完全不测 |

上述“移除／延期”是版本范围，不是数据清理任务。轻量方案是先收紧默认导航和设置，但它只能减少界面复杂度；原生包大小、冷启动和耗电改善需要实际裁剪与测量，当前不提供未测得的节省比例。复用现有路由和 provider 做小范围约束，不新建通用功能开关平台或拆分多个仓库。

### 首屏与导航

建议底栏收敛为 **书架／浏览／更新／更多**。历史移到“更多”并从书架保留继续阅读入口；“更新”只用于收藏漫画的新章节，应用升级留在关于页。浏览提供“来源”和“网页”两个明确入口；首版不把扩展管理作为普通用户的默认起点。

更多页保留软件账号、漫画翻译、历史、下载、分类、数据与存储、设置、帮助／关于。设置聚焦阅读、外观、下载和隐私；动画／小说选择器、追踪账号和服务器配置不出现。沿用已实现的 iOS 原生底栏、页面位置保持和大字号适配，不在首版前重做整套视觉。

### 开发顺序与完成条件

| 顺序 | 工作包 | 可核对的完成条件 |
| --- | --- | --- |
| 1 | 收敛漫画产品入口与启动任务 | 新安装及已有数据升级均只呈现首版功能；深链、备份恢复和已保存偏好不能绕回停用入口；旧数据可备份，隐藏功能不再发起网络请求 |
| 2 | 打稳阅读和翻译闭环 | 本地／已选来源各跑完导入→阅读→翻译→原译切换→离页／后台／进程重启；页码和页内位置合理恢复，失败页不阻塞其他页，结果未知只查原任务，不重复受理或计费 |
| 3 | 完成 iOS 品牌、构建及最小依赖 | 独立显示名、图标、Bundle ID、版本和反馈入口；停止查询／引导下载 Mangayomi 更新；核对视频／BT 框架、权限、后台模式和网络例外；标准 arm64 模拟器及设备 Release／Archive 可重复构建 |
| 4 | 完成账号、隐私与分发方案 | 账号删除可达；图片上传说明与隐私声明一致；确定收费、来源分发和发行地区；准备可审阅的账号／样例、许可证及商店材料 |
| 5 | iOS 真机稳定性与 TestFlight | 至少覆盖一台较低内存设备和一台当前系统设备；完成下述发布门槛，记录真实未决项，再按已选渠道上传候选包 |

独立 Bundle ID 会影响沙盒、钥匙串与已安装测试包的数据继承，实施前先设计备份／恢复与重新登录路径。当前已成功的 `mangayomi://nodelane-auth` 不在规划阶段直接更改；发布身份独立化时再登记新的精确回调、更新原生配置并验证，避免破坏现有登录。保留 `UPSTREAM.md`、LICENSE 与第三方声明，不将上游的 `0.9.9+127` 自动当作 NodeLane 的正式版本。

### iOS 发布门槛

- **功能与恢复**：真实登录、续期、退出／换号；阅读器和网页两个入口分别成功翻译；原译切换、切标签、后台返回、进程回收、断网和低磁盘。不能用一次成功翻译代替这组验收。
- **故障与数据**：取消登录／上传、失效来源、过期任务、额度不足、重复点击与迟到回包；确认原图仍可读、已接受任务可核实、账号结果不串用、备份恢复不覆盖无关数据。
- **性能与系统**：按翻译架构已有预算实测连续阅读与切标签、隐藏后新增请求、资源释放和温升；记录峰值与回落，不把模拟器构建结果当作真机内存或耗电结论。测小屏、大字号、横屏、iOS 返回手势；最低系统版本按实际承诺验证。
- **发行**：设备 Release／Archive、签名与安装升级通过；正式包无测试入口、默认敏感日志或上游更新误跳转。仅将满足设备矩阵的机型／系统列入支持范围。

需提前决定的商店事项是实际发布依赖。动态扩展需按 2.5.2 与 4.7 核对具体实现，不能笼统断言“允许 JS 就能上架”；云翻译付费需核对 3.1，不能自动套用 Reader App 例外；受支持站点需具备相应内容使用许可。以上是本项目的待核对项，不是审核通过结论，见 [Apple 审核指南](https://developer.apple.com/app-store/review/guidelines/)。若登录流程支持注册，即使注册在网页完成，也需在 App 内提供删除账号的发起入口；退出登录不等于删除，见 [Apple 账号删除说明](https://developer.apple.com/help/app-review/guideline-reference/5-1-1-account-deletion)。
