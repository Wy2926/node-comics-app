# 0.2.0 更新规划

开发分支 `0.2.0`，基线 `0.1.4+2005`。按以下顺序交付，平台分别验收。

| 顺序 | 更新项 | 验收条件 |
| --- | --- | --- |
| 1 | Android 内置浏览器使用 GeckoView 和 uBlock Origin，盾牌复用 App 的站点保护抽屉 | 首次离线可加载扩展；默认拦截、本站停用与恢复；登录、取图翻译、查找、标签切换与位置恢复回归 |
| 2 | 书架和更新页停止刷新 | 两页操作同一任务；来源卡住也能停止；已完成结果保留，新一轮不受旧回调影响 |
| 3 | 章节失败说明与恢复 | 区分网络、登录、限流、来源无图、本地文件和未知错误；给对应动作，单页重试保留位置 |
| 4 | 来源页筛选与折叠页头 | 单行横滑、展开多选、清空与结果数；下滑收成筛选摘要，上滑展开，返回保留条件与位置 |
| 5 | 精准续读 | 书架最近阅读一键回到原章原页；检查切换阅读方向后位置，不留空卡 |
| 6 | 同日同作品的更新合并 | 可展开逐章阅读或下载；一键从首个未读章开始 |
| 7 | 章节错误页换站试读 | 带书名复用跨来源搜索，确认匹配后才迁移书架 |
| 8 | 译图快速对照 | 阅读器和浏览器按住工具栏看原图，松开恢复；不移动位置、不新增翻译任务 |

iOS 后续从本分支接入 WebKit 扩展，这一步保留当前浏览器与构建目标。最低 iOS 版本可按实际扩展要求调整，不以兼容 iOS 15 为前提。通用扩展安装与管理在广告扩展之后验收；至少用一个非广告扩展验证安装、启停与卸载，再对外宣称支持。

**当前进度：** 第 1、4 项已接入，平台验收见[移动端验证边界](MOBILE_UI_DESIGN.md#验证边界与待办)；第 2、3、5–8 项待实施。iOS 可直接沿用本分支的 `BrowserPageController.protection` 接入站点保护面板，沿用 `ReaderTransport` 对接网页翻译，书签、历史和逻辑标签不需要另建存储。

浏览器修复的对照页、性能数据与验收边界见[内置浏览器验证](BROWSER_REVIEW.md)。
