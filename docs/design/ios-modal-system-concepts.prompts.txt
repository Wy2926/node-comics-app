NodeLane 模态组件统一设计参考
生成方式：内置 image_gen，未使用 CLI/API 后备方式。
状态：布局已确认并接入共享组件。确认后的修订：有范围的数字从当前控件浮出 iOS 风格滚轮，不展开页面、不推入模态路由；字段名称放输入框上方，复用搜索框的底色、细边、圆角和阴影，单字段去掉重复标题；URL 保持单行横向输入。原生成提示词和图像保留用于素材溯源，当前实现与验收边界见 MOBILE_UI_DESIGN.md。
视觉依据：当前 NodeLaneTokens / nodeLaneModalTheme、NodeLaneTextField / NodeLaneRow / NodeLaneNotice；现有通知和搜索组件概念图仅用于视觉对照，不沿用旧图中已被替换的表单结构。
素材：按项目令牌描述生成，无新增字体、图标包或第三方图片。界面文案、作品、数量、版本说明为示例。

组件归并：6 类基础构件，4 种组合布局。组件数量指职责分类，不等于要新增 6 个 Dart 类；沿用原组件演进，实施后移除被替代的重复外壳、布局与样式。
1. 模态外壳：居中、底部、全屏三种呈现；复用 NodeLaneModalScope、NodeLaneGlassSurface、NodeLaneDialog / NodeLaneCatalogSheet 的现有职责；不新建平行主题。
2. 标题与说明区：复用并泛化 NodeLaneReaderHeading；标题、作用范围、可选返回/关闭；普通确认不重复显示关闭和取消。
3. 操作区：从现有 actions/bottom 中提取统一排列；普通、危险、禁用、执行中；业务能力决定取消或重试。
4. 表单字段：复用 NodeLaneTextField；单行、多行、数字、URL、密码和搜索；名称在输入框上方，输入区与搜索框共用令牌表面。
5. 选项与操作列表：复用 NodeLaneRow、NodeLaneGroupSurface、NodeLaneSwitchRow、NodeLaneSliderRow、NodeLaneDisclosure；单/多选、菜单、摘要、可展开详情。
6. 状态反馈区：复用 NodeLaneNotice / 现有空态；信息、加载、进度、失败、部分完成；无新通知系统。

组合布局及覆盖范围：
确认与删除：普通确认、删除/清理、退出、解除关联、同步上传下载、覆盖/恢复、重复作品三项决策、来源/脚本导入确认。
输入与编辑：分类名称、本地作品信息、URL/DNS/User-Agent、数字参数、音频语言、追踪进度、邮箱与密码、备份密码、仓库地址、来源文本与保存搜索、Torrent/磁力链接。
选择与操作：单/多选、来源筛选、分类与来源选择、搜索目录、网站/仓库/图片/书架更多、阅读/播放即时设置。动态字段与选项必须以现有来源契约为准。
状态与内容：进行中、失败、部分完成、说明/帮助、更新信息、追踪资料卡、标签页预览、图片全屏预览。媒体/标签内容沿用已有组件，只统一模态外壳；不为每种内容另建基础组件。

交互约束：短弹层随内容收缩，长内容达到最大高度后滚动；重要说明放标题下方。普通确认取消左、主要操作右；危险操作仅主按钮与必要危险标识使用主题 error 色。编辑/多选操作保持草稿，确认再交还原业务；单选/即时设置遵循原提交语义。字段名称始终在框上方，不占输入宽度；不叠加第二层输入底板。编辑抽屉的操作区位于键盘上方。关闭/取消避免重复。执行中防重复触发；是否允许中断、重试、关闭由现有任务能力决定，未知结果先核实。恢复不可中断时不显示取消、关闭、拖动提示。普通成功继续复用现有临时通知。页内错误保留输入，不再叠加第二个错误弹框。
令牌：居中标题20、抽屉标题22、正文16、行/字段标签17、辅助14、按钮/值15；间距4/8/12/16/20/24；边距20，行内边距16；外壳24、分组18、iOS按钮/独立输入24；表单/搜索输入与建议主按钮48、点击区至少44；常规图标24、辅助20。图像生成不是像素测量基准，准确尺寸与主题色以共享代码令牌为准。
平台边界：系统文件/目录、分享、OAuth、生物认证保留系统管理；已有全页设置/迁移/备份冲突页不改成模态框。
系统提示不重绘：文件/目录选择、系统分享、OAuth、Face ID/Touch ID。桌面/电视仍可共用语义组件，具体替换范围见当前界面文档；本轮无 Android 运行验收。
